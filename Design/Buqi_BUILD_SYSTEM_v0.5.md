## 1. 构筑方向（保留自 C01/C02，8 方向有效）

| Build | 中文包装 | 核心计划 | 被克制点 |
|---|---|---|---|
| fast | 攻击快攻 | 用加速和充能提前打出伤害窗口 | 护盾、冰冻 |
| buffer | 护盾反击 | 先叠护盾，再用护盾破裂触发反击 | 中毒 |
| chain | 充能连锁 | 依靠相邻装备互相充能，放大核心攻击 | 冰冻、减速 |
| heal | 治疗续航 | 用治疗和再生熬过爆发 | 中毒、冰冻核心治疗 |
| poison | 中毒消耗 | 无视护盾压低生命，逼对手带治疗 | 快攻 |
| burn | 灼烧压迫 | 持续消耗护盾，再用攻击压死 | 大护盾、治疗 |
| freeze | 冰冻控制 | 冻住敌方关键装备，打乱出手节奏 | 多小件分散目标 |

> 注意：这些是**分析标签**，不是职业或硬克制关系。原 8 方向的"过载爆发"随过载词条一并删除，现为 7 方向。

## 2. 词条语义（对齐契约 v0.6.0，修正 C02 冲突项）

| 内部枚举 | 玩家词条 | 结算规则（对齐大巴扎） |
|---|---|---|
| Damage | 攻击 | 先被护盾阻挡，护盾耗尽后扣生命 |
| Shield | 护盾 | 阻挡伤害；中毒绕过；对灼烧减伤 50% |
| Heal | 治疗 | 恢复至上限；清除 10% 中毒与灼烧（向上取整） |
| Regen | 再生 | 每秒恢复配置量；可被暴击 |
| Poison | 中毒 | 每秒造成当前层数伤害，绕过护盾 |
| Burn | 灼烧 | 每秒 2 点、每次结算层数 −1；有护盾减伤 50% |
| Freeze | 冰冻 | 冻结期间不充能、不能使用 |
| Haste | 加速 | 充能速度 2 倍 |
| Slow | 减速 | 充能速度 0.5 倍；与加速互斥 |
| Charge | 充能 | 立即推进冷却（一次性，≠加速） |
| Crit | 暴击 | 有几率效果翻倍（伤害/治疗/护盾/再生/灼烧/中毒） |
| Multicast | 多重 | 一次使用重复执行多次 |
| Ammo | 弹药 | 耗尽停止充能、战后补满；容量 0=无限 |
| Flight | 飞行 | 受减速/冰冻时长减半 |
| Value | 价值 | 经济收益（装备价值成长/出售价/金币）；阿瓷专属为主 |

C01 §16 原非目标"暴击、弹药、召唤、摧毁、偷取、随机目标、角色专属卡池、在线匹配"中，**以下已转正**：

- **暴击 / 多重 / 弹药 / 飞行** —— 战斗契约已实现（见 §2）。
- **角色专属卡池** —— 英雄系统 v0.1 已定（4 英雄专属池 + 通用池，见 §4）。

**已删除词条**：过载、怒气（用户评审决定，不再作为词条与构筑方向）。

**仍为非目标（首阶段）**：召唤、摧毁(Destroy)、偷取、随机目标、在线实时匹配、英雄"道途特质"的战斗内实现（会心叠层/阵律执法/道影复刻，属战斗契约后续版本，延后）。

## 4. 装备归属（300 件 → 英雄池，Hero 字段）

- **现状**：Luban `DTBuqiItem` 现有 300 件（W8-001..W8-300）；C02 的 24 件为 8/5 历史快照，不再作为范围依据。
- **归属原则**（详见 buqi-heroes.md §3.2）：
  - `fast / 暴击 / 多重 / 弹药` → 闻辛专属为主；`buffer / freeze` → 裴照川专属为主；`chain / 加速` → 荀照专属为主；`heal / 经济 / 修复 / 价值` → 阿瓷专属为主。
  - `poison / burn` → 主体入通用池，各英雄专属池渗入 2~3 张变体。
- **数据变更**：`DTBuqiItem` 增 `Hero` 字段（0=通用，1=阿瓷，2=闻辛，3=裴照川，4=荀照）；商店/事件/PvE 掉落/突破三选一按当前英雄过滤。
- **交付**：300 件全部完成归属（Hero 非空），归属表随卡池 DB 交付（门禁 `Test-BuqiItemCatalog.ps1`）。

## 5. 数值与节奏（对齐契约）

- **沙暴**：tick 300（30 秒）开始，**无硬上限**，伤害 `StormBaseDamage + (tick−300)×StormRampDamage`（**推翻 C01 §9 的"60 秒战斗预算"**）。
- **生命/护盾基准**：**初始生命值 400（全英雄一致）**；护盾上限 [待回填]（以 Luban 表为准，进调优登记）。
- **战斗时长**：不再设固定预算；长局由沙暴递增伤害自然终结（与"无限天 + 渡劫"的压迫感一致）。

## 6. 保留的设计思路（自 C01）

- 体验支柱（词条一眼可读 / build 各有代价 / 战后能改动 / 状态不是装饰）。
- 决策深度示例（不同局面最优动作随生命/护盾/DOT/冷却翻转）。
- 三层展开（探索期→成长期→成熟期）与教学节拍。
- 失败反馈三要素（主要失血来源 / 被打断或未触发的核心装备 / 下一轮可改方向）。
