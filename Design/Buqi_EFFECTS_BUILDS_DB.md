# 不器词条与构筑 DB

## 玩家词条

| 内部枚举 | 玩家词条 | 结算规则 |
| --- | --- | --- |
| Damage | 攻击 | 先扣护盾，剩余扣生命 |
| Buffer | 护盾 | 加到护盾池，上限 60 |
| Heal | 治疗 | 立刻回复生命，不超过最大生命 |
| Regen | 生命恢复 | 每 10 tick 回复一次生命 |
| Poison | 中毒 | 每 10 tick 直接扣生命，不被护盾吸收 |
| Burn | 灼烧 | 每 10 tick 造成伤害，先被护盾吸收 |
| Freeze | 冰冻 | 目标装备暂停冷却推进 |
| Haste | 加速 | 提高目标装备冷却推进速度 |
| Delay | 减速 | 降低敌方装备冷却推进速度 |
| Charge | 充能 | 增加目标装备充能，供消耗型攻击读取 |
| Noise | 过载 | 自身风险值，达到阈值触发事故伤害 |

## 构筑方向

| Build | 中文包装 | 核心计划 | 被克制点 |
| --- | --- | --- | --- |
| fast | 攻击快攻 | 用加速和充能提前打出伤害窗口 | 护盾、冰冻 |
| buffer | 护盾反击 | 先叠护盾，再用护盾破裂触发反击 | 中毒 |
| chain | 充能连锁 | 依靠相邻装备互相充能，放大核心攻击 | 冰冻、减速 |
| heal | 治疗续航 | 用治疗和生命恢复熬过爆发 | 中毒、冰冻核心治疗 |
| poison | 中毒消耗 | 无视护盾压低生命，逼对手带治疗 | 快攻 |
| burn | 灼烧压迫 | 持续消耗护盾，再用攻击压死 | 大护盾、治疗 |
| freeze | 冰冻控制 | 冻住敌方关键装备，打乱出手节奏 | 多小件分散目标 |
| overload | 过载爆发 | 用过载风险换充能和护盾节奏 | 长局、中毒 |
