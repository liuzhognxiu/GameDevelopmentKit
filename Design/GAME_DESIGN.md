# 《不器》效果词条与 Build 扩展设计

日期：2026-08-05  
状态：B 方案执行稿  

## 1. 一页体验定义与玩家承诺

玩家身份：玩家是来到不器城参加百炼问道的散修，用买来的装备拼出一套会自动运转的构筑。

核心动作：购买、替换、升级、改造、摆位、预判、观战、复盘和调整。

世界响应：双方构筑在战斗中按同一套冷却、触发、词条和状态规则自动运行，战后用日志解释胜负原因。

目标感受：玩家应觉得自己调出了一台能被读懂、能被针对、也能反制对手的自动战斗机器。

## 2. 类型落地与对标原则

本作借鉴异步自动构筑游戏的三个核心动词：买、摆、看。买决定资源取舍，摆决定空间关系，看决定战后修正方向。

本作刻意不借传统装备的手牌、回合出牌和抽牌排序；也不把完整线上 PvP、英雄职业池和大量特殊例外作为第一批扩展目标。

这次扩展的独有落点是：把旧的抽象词条改成玩家一眼能懂的战斗词，例如攻击、护盾、治疗、中毒、灼烧、冰冻，并让每个 build 都通过这些词条形成可验证的取舍。

## 3. 前提上屏文案

首屏标题：不器城百炼问道

首屏一句话：摆好你的装备，让它们自己攻击、护盾、治疗和控场；战后看清败因，再改一次构筑。

对手预览屏：这份对手快照主打「{BuildName}」，关键威胁是「{KeyEffect}」。

战后总结屏：你输给了「{Cause}」。下一战可以调整位置、补护盾、换治疗，或打断对方核心装备。

## 4. 三段展开

| 阶段 | 新增可做的事 | 可达空间 | 结束标记 |
|---|---|---|---|
| 探索期 | 认识攻击、护盾、加速、减速、充能、过载的旧六词条新包装 | 3 个基础 build、6 个教学对手快照 | 第 2 枚胜场 |
| 成长期 | 引入治疗、生命恢复、中毒、灼烧、冰冻 | 8 个 build、16 个对手快照 | 第 4 枚胜场 |
| 成熟期 | 用 8 个 build 互相克制和混搭，读懂对手并主动转向 | 8 个 build、24 个对手快照样例 | 通关或单局生命耗尽 |

差集成立：探索期只能做数值和节奏取舍；成长期能做持续状态与恢复取舍；成熟期能做跨 build 混搭和针对性控场。

## 5. 体验支柱

| 支柱 | 可观察证据 | 否决现象 |
|---|---|---|
| 词条一眼可读 | 新玩家能说出攻击打血、护盾挡攻击、治疗回血 | 玩家仍用生命值、护盾、过载等内部词解释战斗 |
| build 各有代价 | 每个 build 至少有一个明显克制者和一个明显软肋 | 某 build 在大多数代表局只靠更大数字通吃 |
| 战后能改动 | 玩家能根据败因提出购买、改造或摆位改法 | 玩家只说“对面数值更高” |
| 状态不是装饰 | 中毒、灼烧、冰冻至少各有一个规则读点 | 新状态只在 HUD 上变化，不改变决策 |

## 6. 两层循环与熟练度类型

5-30 秒短循环：观察双方冷却和状态 -> 装备自动触发 -> 攻击、护盾、治疗或状态变化显示 -> 玩家看见哪个 build 的计划正在成立。

1-5 分钟长循环：战前预览 build -> 调整构筑 -> 自动战斗 -> 战后归因 -> 下一轮购买或摆位修正。

普通玩家主要学会词条因果；熟练玩家会读冷却窗口、状态持续时间、护盾是否足以覆盖灼烧、治疗能否追上中毒。熟练度类型是可再生判断，每局都要重新读局面。

## 7. 类型契约

只保留会影响玩家决策的字段：生命、最大生命、护盾、攻击、治疗、生命恢复、中毒、灼烧、冰冻、加速、减速、充能、过载、冷却、尺寸、位置、标签、品质、改造、对手 build 预览。

不把隐藏战力、胜率预测、动态克制倍率、随机战斗目标或战斗中主动技能纳入本阶段。

## 8. 世界规则与状态、必要系统

| 规则 | 玩家可见因果 | 消费点 | 读取点 |
|---|---|---|---|
| 攻击 | 攻击先被护盾吸收，剩余扣生命 | 攻击值、护盾值 | 战斗结算、护盾吸收日志 |
| 护盾 | 当前护盾保护生命，但不挡中毒 | 护盾值、护盾上限 | 攻击结算、护盾破裂触发 |
| 治疗 | 立刻恢复生命，不超过最大生命 | 治疗值、生命上限 | 生存时间、治疗贡献 |
| 生命恢复 | 持续数秒逐跳治疗 | 恢复值、持续时间 | 每秒结算、治疗贡献 |
| 中毒 | 每秒直接损失生命，不被护盾吸收 | 中毒层数、持续时间 | 生命结算、续航压力 |
| 灼烧 | 每秒造成可被护盾吸收的伤害 | 灼烧层数、持续时间 | 护盾压力、伤害贡献 |
| 冰冻 | 目标装备暂停冷却推进 | 冰冻时长、目标选择 | 冷却推进、被控时长 |
| 过载 | 高收益装备积累风险，跨阈值自伤 | 过载值、事故伤害 | 事故日志、风险 build |

核心系统：自动战斗词条与状态结算。

支持系统一：8 格棋盘与相邻关系。

支持系统二：Build/对手快照 DB，用公开情报把对手变成可读题目。

## 9. 数值预算表

| 门槛 | 起始值 | 单次典型增减 | 最少动作数 | 合格线路 |
|---|---:|---:|---:|---|
| 生命归零 | 100 | 攻击 4-16，DOT 每秒 2-5 | 8-14 次有效输出 | 4 次小攻击 + 3 次中型攻击 + 1 次大招约 56-80，需状态或加速补足 |
| 护盾可见 | 0/60 | 单次 +6 至 +14 | 1 次 | 4 秒内获得 7 护盾，可挡一轮小攻击 |
| 治疗可翻盘 | 100 上限 | 单次 +6 至 +12，恢复每秒 +2 至 +4 | 2-4 次 | 低血局用治疗多争取 6-10 秒 |
| 中毒成立 | 0/30 | 每次 +2 至 +5，持续 4-8 秒 | 3 次 | 3 次叠毒后每秒直扣 6，逼治疗或速攻回应 |
| 冰冻可读 | 0 秒 | 单次 0.5 至 1.5 秒 | 1 次 | 冻结核心 L 装备 1 秒能延后一次关键触发 |

最高门槛在 60 秒战斗预算内可达，但需要多次正确购买、摆位或触发，不靠单次大数字通关。

## 10. 决策深度示例

| 局面 | 攻击 | 护盾 | 治疗 | 中毒 | 冰冻 |
|---|---:|---:|---:|---:|---:|
| 我方生命 80，对方护盾 0，敌核心 5 秒后触发 | 最优：压血 | 次优 | 浪费 | 中等 | 次优 |
| 我方生命 30，中毒每秒 6，对方护盾 25 | 低效 | 中等 | 最优：争时间 | 低效 | 次优 |
| 对方灼烧每秒 8，我方护盾 10，治疗冷却快好 | 中等 | 最优：挡燃烧 | 次优 | 中等 | 低效 |
| 对方 L 核心 1 秒后触发，我方输出足够但慢 | 次优 | 低效 | 低效 | 中等 | 最优：打断窗口 |

最优动作会随生命、护盾、DOT 和敌方冷却状态翻转，不存在超过 60% 代表局通吃的单一选择。

## 11. 品类保真 Go/No-Go

| 问题 | 结论 | 可验证证据 |
|---|---|---|
| 世界/对手是否也用核心系统出招 | go | 对手快照使用同一组 build、词条和状态结算 |
| 非教学回合是否有真实选择 | go | 每轮至少出现买输出、补防御、买控制、转续航中的两条可行路线 |
| 签名幻想是否落在重复核心动词 | go | 每个 build 都通过买、摆、看、改闭环成立 |
| 核心系统是否提供非被支配选项 | go | 攻击、护盾、治疗、中毒、灼烧、冰冻在不同局面各有最优窗口 |

## 12. 关卡节拍

教学：只给攻击、护盾、治疗三词条，30 秒内强制开战一次，让玩家看到护盾吸收和治疗回血。

变式：加入中毒或灼烧，对手快照用单一持续伤害 build，玩家必须选择护盾或治疗路线之一。

组合：引入冰冻和充能连锁，允许玩家发现“冻住核心”或“加速自己”的两种解法。

检验：给 8 个 build 的混合对手快照，绑定两条基准策略：纯攻击与补防混合。纯攻击应能过一部分局但会明显输给护盾/冻结题。

命运回收：通关结算回读玩家最常使用的 build 与一次关键转向，例如“你在第四战放弃纯攻击，改用护盾挡住了灼烧”。

## 13. 首屏焦点与披露状态

第一帧唯一焦点：中央棋盘。

次级面板初始状态：词条详情折叠，仅显示生命、护盾、关键状态图标和对手 build 名。

披露触发：鼠标悬停或长按词条时显示“攻击先打护盾”“中毒不被护盾挡”“冰冻暂停冷却”等因果短句。

## 14. 反馈与失败

失败必须显示三类事实：主要失血来源、被打断或没触发的核心装备、下一轮可改变的方向。

例：你不是因为生命低而输，而是“小型冰冻冻住了灼烧攻击 2 次，灼烧没有叠起来”。下一轮可以换位置、补加速、或购买抗控改造。

## 15. 社交表现假设

首阶段仍是单人 + 离线对手快照的假多人表现。对手快照展示为同规则快照，不连接服务器、不上传玩家构筑、不做实时 PvP。

## 16. 最小试玩问题、范围与验收

最大假设：通俗词条能显著降低理解成本，同时新增状态不会把自动战斗变成不可读黑箱。

最小试玩范围：8 个 build、24 张装备、16 个对手快照，单局 8-12 分钟。

非目标：暴击、弹药、召唤、摧毁、偷取、随机目标、角色专属卡池和在线匹配。

验收：玩家战后能用攻击、护盾、治疗、中毒、灼烧、冰冻这些词解释至少一个败因，并在下一轮做一次对应修正。

## 17. 角色内容层级与升级门

氛围人物只负责介绍不器城和商店口吻。

支持短线可以给一名对手快照制作者一个有后果选择，例如是否保留其危险过载装备；后续回读该选择。

核心路线不在本次扩展升级，除非试玩证明玩家已经会主动讨论 build 身份和对手快照来源。

## 18. 受众、文化与语言范围

首发界面语言为中文。玩家可见词条采用通俗现代战斗词：攻击、护盾、治疗、生命恢复、中毒、灼烧、冰冻、加速、减速、充能、过载。

文案声口要求短、清楚、少术语。玄幻包装服务识别度，不能把规则重新藏回晦涩名词里。
