# 术语表（前置知识速查）

阅读本知识库前的必读背景：本仓库是 **Unity + ET 8.1 双模式游戏开发框架**。以下术语在文档中高频出现。

## 核心框架
| 术语 | 全称/含义 | 说明 |
| --- | --- | --- |
| **GDK** | GameDevelopmentKit | 本仓库：Unity 客户端 + ET 服务端一体化框架 |
| **GF / UGF** | UnityGameFramework | 客户端底座框架（EllanJiang/UnityGameFramework），提供资源/场景/实体/UI/音频/事件等模块化组件 |
| **ET** | 无（框架名） | egametang/ET 8.1：C# 服务端 + ECS 风格客户端框架，Entity/Component/System 模式 |
| **UGFExtensions** | UnityGameFramework.Extension | GDK 对 UGF 的扩展库（AssetSet/NetworkService/Screen/Collection 等） |

## 运行模式（重点）
| 术语 | 含义 |
| --- | --- |
| **UNITY_GAMEHOT** | 纯 GF 模式宏：业务代码用 MonoBehaviour + GF 组件，程序集 `Game.Hot.Code` |
| **UNITY_ET** | ET 模式宏：业务代码用 Entity + System + Fiber，四程序集 Model/Hotfix/ModelView/HotfixView |
| **UNITY_HOTFIX** | 热更叠加宏：业务程序集转 `.dll.bytes` 资源，HybridCLR 运行时加载 |
| **GameHot / Code/** | 热更业务代码目录（`Game/Hot/Code/`） |
| **Loader/** | 稳定加载层（`Game/Hot/Loader/`、`Game/ET/Loader/`），不参与业务热更 |
| **CodeRunner** | UGF Extension 组件，负责加载热更代码并启动 |

## ET 概念
| 术语 | 含义 |
| --- | --- |
| **Entity / Component / System** | ET 三大要素：实体（数据容器）、组件（挂实体上）、System（逻辑函数） |
| **Fiber** | ET 纤程：轻量级并发单元，服务端每 Scene/进程可多 Fiber |
| **Scene / SceneType** | 场景实体与场景类型（位标记，`HasSameFlag` 判断） |
| **Model/Hotfix/ModelView/HotfixView** | ET 四程序集分层：纯数据/逻辑/视图数据/视图逻辑 |
| **DynamicEvent** | GDK 扩展：按实体类型 + SceneType 广播事件 |

## 数据与配置
| 术语 | 含义 |
| --- | --- |
| **Luban** | 配置表工具：Excel → 二进制/JSON + C# 代码 |
| **DRxxx / DTxxx** | Luban 生成类命名：`DR`（DataRow 单行）/`DT`（DataTable 表访问器），如 `DRScene`/`DTScene`；表访问统一走 `GameEntry.Tables.DTxxx` |
| **Proto2CS** | 协议生成工具：.proto → ET(MemoryPack)/UGF(Protobuf) 代码 |
| **Opcode** | 消息号：ET 10000/20000 段、GameHot 30000 段 |
| **Generate/** | 自动生成目录，勿手改 |

## 资源与热更
| 术语 | 含义 |
| --- | --- |
| **HybridCLR** | 热更新方案：AOT 补充元数据 + IL 解释执行热更程序集 |
| **AssetSet** | GDK 资源设置组件：以 Target+Path+Type 管理图片/纹理设置生命周期 |
| **AssetUtility** | 资源路径统一收口工具 |
| **link.xml** | Unity 代码裁剪配置（模式切换时自动维护） |

## 服务端
| 术语 | 含义 |
| --- | --- |
| **DotNet/** | ET 独立服务端工程（App/Loader/Hotfix/Model/Core/ThirdParty） |
| **Admin** | 服务端管理后台（Blazor + MudBlazor，默认 5200 端口） |
| **Agent** | 本机部署代理：管理本机进程的启停/热重载/部署 |
| **KCP / TCP / WebSocket** | 服务端支持的三类网络传输（KService/TService/WService） |
| **Recast/Detour** | 寻路库：Unity 导出导航网格，服务端计算路径，客户端表现移动 |
| **Aspire / FileServer** | 进程编排器 / 热更资源文件服务器（8088） |

## 开发辅助
| 术语 | 含义 |
| --- | --- |
| **CodeBind** | 代码与 UI 组件自动绑定（生成 m_xxx 字段） |
| **ReactiveBinding** | 响应式数据绑定（数据变化自动刷新 UI） |
| **StateController** | UI 状态组控制（显隐/样式切换） |
| **UniTask** | 零 GC 异步框架（替代 async/await 的 Unity 版） |
| **MemoryPack / Protobuf** | ET 与 UGF 各自的序列化方案 |
| **Roslyn Analyzer** | 编译期静态分析规则（ET0001~ET0032），强制 ET 编码规范 |
| **SourceGenerator** | 增量代码生成器（System/Handler/序列化/响应式） |
