# 模块 04：UI 窗体与 ETUI

> Catalog ID: `UNITY-04`、`ET-05`  
> 状态：`verified`  
> 最后核验：`2026-08-03`  
> 适用模式：GameHot Client / ET Client

## 模块定位

UI 资源、分组、加载和实例池由 UGF `UIComponent` 管理。项目基础层提供 `AUIForm`、Widget、异步打开和深度同步；GameHot 直接在 MonoBehaviour UIForm 中编写业务；ETUI 则把 UGF Mono 视图绑定到 ET `UGFUIForm`/`UGFUIWidget` Entity，并把 UGF 生命周期转发给 ET System。

## 依赖关系

```text
Luban UI.xlsx
  -> DRUIForm / DTUIForm + UIFormId
  -> Game.UIExtension
  -> UGF UIComponent
  -> prefab 上的 UIFormLogic
     -> GameHot: StarForceUIForm
     -> ET: AETMonoUGFUIForm <-> UGFUIForm Entity <-> HotfixView System
```

GameHot UI 依赖 `Game.Hot.Code` 和 `AHotUIForm`。ETUI 的 Entity/Mono 定义位于 ModelView，System 位于 HotfixView；稳定的生命周期转发器位于 `Game.ET.Loader`。

## 入口与调用链

### GameHot

```text
GameEntry.UI.OpenUIForm(UIFormId.X, userData)
  -> UIExtension 从 DTUIForm 取 AssetName/UIGroup/AllowMulti/PauseCovered
  -> UGF UIComponent 加载并实例化 prefab
  -> UIFormLogic.OnInit（实例首次初始化）
  -> OnOpen（每次打开）
  -> 业务 StarForceUIForm
```

`StarForceUIForm` 在 OnInit 设置主字体并按 Text 内容查本地化字符串，在 OnOpen/OnResume 执行 CanvasGroup 淡入。主字体由 GameHot Preload 提前设置。

### ETUI

```text
scene.UIComponent.AddUIFormComponentAsync<T>(UGFUIFormId.X)
  -> 创建 UGFUIForm Entity
  -> UGFUIForm.OpenUIFormAsync
  -> GameEntry.UI.OpenUIFormAsync(..., ETMonoUGFUIFormData)
  -> AETMonoUGFUIForm.OnOpen 消费 pooled data
  -> 双向绑定 Entity.UGFMono / Mono.UGFUIForm / CachedTransform
  -> 把直接子 AETMonoUGFUIWidget 建成 ET 子 Entity
  -> UGFSystemSingleton 调用 [UGFUIFormSystem] 对应生命周期 System
```

真实调用见 `AppStartInitFinish_CreateLoginUI`，它在 Demo Scene 事件中打开 `UIFormLoginComponent`。

## 核心类型与 API

| 类型/API | 职责 | 生命周期/约束 |
| --- | --- | --- |
| `AUIForm` | UGF UIFormLogic 基类 | OnInit 补 Canvas、GraphicRaycaster 并铺满 RectTransform |
| `AUIForm.OnDepthChanged` | 同步子 Canvas 与 ParticleSystemRenderer 层级 | 使用 UIGroup 与 Form 深度计算增量 |
| `AExUIForm` | 带 Widget/Event/Entity/Resource 容器的窗体 | OnClose 自动清理受管资源 |
| `AUIWidget` / `AExUIWidget` | prefab 内复用 UI 单元 | Initialized、Available、Visible 分离 |
| `UIExtension.OpenUIForm` | 按配置同步打开 | 非多实例时拒绝重复加载/已打开实例 |
| `UIExtension.OpenUIFormAsync` | 可取消异步打开 | 返回 null 代表配置缺失或重复实例 |
| `UGFUIForm<TMono>` | ET UI Entity，强类型 View | Dispose 取消打开请求并关闭 UGF Form |
| `AETMonoUGFUIForm` | UGF Mono 到 ET Entity 的桥 | OnOpen 必须收到 `ETMonoUGFUIFormData` |
| `UGFUIWidget` | ET Widget Entity | 可作为 Child 或 Component 挂载 |
| `UGFSystemSingleton` | 转发 UIForm/UIWidget 生命周期 | 仅调用 Entity 实现的生命周期接口 |

## 数据与生命周期

UGF Form 生命周期包括 OnInit、OnOpen、OnPause/Resume、OnCover/Reveal、OnRefocus、OnUpdate、OnDepthChanged、OnClose、OnRecycle。OnInit 对池中实例通常只执行一次；OnOpen/OnClose 每次可用周期执行。

`AUIForm` 调整根 Canvas 和所有子 Canvas/粒子 renderer 的 sortingOrder。`AExUIForm` 只自动收集“最近父 Form 是当前 Form”的 `AExUIWidget`，避免把嵌套 Form 的 Widget 错归属。

ETUI 在 Mono OnOpen 时完成 Entity/View 绑定。关闭时先关闭 Widget 并分派 ET OnClose，然后解除容器；ET Entity Dispose 会关闭仍可用的 UGF Form。异步打开使用池化 `CancellationTokenSourcePlus`，Entity 销毁会取消请求。

## 开发扩展步骤

### 新建 GameHot UIForm

1. 在 `Unity/Assets/Res/UI/UIForm/Hot` 创建 prefab，根逻辑继承 `StarForceUIForm` 或合适的共享基类。
2. 在 GameHot `UI.xlsx` 增加唯一 Id、CSName、AssetName、UIGroupName、AllowMultiInstance、PauseCoveredUIForm。
3. 运行 Luban 导出，使用生成的 `UIFormId`；不要手工增加常量。
4. 在 `Game/Hot/Code/UI` 编写 partial UI 类并使用 CodeBind 生成绑定字段。
5. 使用 `GameEntry.UI.OpenUIForm(UIFormId.X, userData)` 或 Async 版本打开。

### 新建 ETUI Form

1. 创建 prefab，Mono 类继承 `AETMonoUGFUIForm`。
2. 在 ET `UI.xlsx` 配置并导出 `UGFUIFormId`。
3. 在 ModelView 创建 `UGFUIForm<TMono>` Entity，声明 `IAwake` 和需要的 `IUGFUIFormOn*` 接口。
4. 在 HotfixView 创建 `[EntitySystemOf]` partial System；生命周期方法标记 `[UGFUIFormSystem]`。
5. 从 Scene 的 `UIComponent` 调用 `AddUIFormChildAsync` 或 `AddUIFormComponentAsync`。需要同类型多实例时使用 Child；唯一 Form 可使用 Component。

### 新建 Widget

GameHot 使用 `AExUIWidget` 并由 Form/父 Widget 容器管理。ET 使用 `AETMonoUGFUIWidget + UGFUIWidget<TMono>`；静态子 Widget 在 Form/父 Widget OnOpen 时自动建 Entity，动态 Widget 可通过 UIEntity 加载 API 创建。

## 约束与常见错误

- UI 表中的 AssetName 必须与资源规则生成的 `AssetUtility.GetUIFormAsset` 路径一致。
- `AllowMultiInstance=false` 时，正在加载或已经打开都会返回 null；调用方不能假设必有实例。
- `StarForceUIForm.OnInit` 依赖主字体已由 Preload 设置；绕过正常启动链会得到 invalid font 日志。
- `AETMonoUGFUIForm.OnOpen` 强制把 userData 转成 `ETMonoUGFUIFormData`，不能直接用普通 UGF Open API 打开 ET prefab。
- ET Entity 声明了生命周期接口但没有对应 `[UGFUIFormSystem]` 时，转发器找不到行为；反之未声明接口则不会分派。
- 关闭 ETUI 应 Dispose/移除对应 Entity，让 Entity 与 UGF Form 生命周期保持一致。
- `OnDepthChanged` 会修改所有子 Canvas/Particle 的当前 sortingOrder，prefab 内应使用相对层级且避免其他脚本重复累加。
- UI prefab 和生成 ID 都是模式相关资源；切换 ET/GameHot 后必须重新导表并刷新资源规则。

## 验证方法

1. 导表后确认 DTUIForm 和对应模式 UIFormId 生成成功，Unity 无编译错误。
2. 打开/关闭同一 Form 两次，确认 OnInit 一次、OnOpen/OnClose 两次，并验证实例池复用。
3. 验证 `AllowMultiInstance`、UIGroup、PauseCovered 和 Refocus 行为。
4. 打开带粒子和嵌套 Canvas 的 Form，检查不同 UIGroup/深度下排序正确。
5. ET 模式验证 Entity Dispose 能取消加载或关闭 Form，所有声明的生命周期 System 被调用。
6. 动态 Widget 验证加载、父子归属、Depth 更新、关闭和回收。
