# 模块 09：音频模块

> Catalog ID: `UNITY-09`  
> 状态：`verified`  
> 最后核验：`2026-08-04`  
> 适用模式：GameHot / ET Client / Unity Runtime

## 模块定位

音频模块在 UGF `SoundComponent` 上提供表驱动的背景音乐、业务音效和 UI 音效 API，并统一管理声音组静音、音量与 Setting 持久化。它不负责音频导入设置、混音器制作或配置表生成本身。

## 依赖关系

- 上游依赖 UGF Sound、GF `PlaySoundParams`、Luban `TablesComponent`、`AssetUtility` 和 Setting。
- `PlaySound(AEntity)` 依赖项目 Entity 包装，实际把底层 UGF `Entity` 作为声音绑定对象。
- `ProcedureLaunch` 恢复音频设置；`ProcedureChangeScene` 停止声音并按 `DRScene.BackgroundMusicId` 播放音乐。
- GameHot 实体、AboutForm、SettingForm 和 `ProcedurePreset` 是当前真实调用者。
- ET Client 可复用 `GameEntry.Sound` 扩展和 ET 生成的 UGF 音频 ID，不依赖 GameHot UI。

## 入口与调用链

背景音乐：

```text
PlayMusic(musicId)
  -> StopMusic() 淡出上一首
  -> DTMusic.GetOrDefault
  -> PlaySoundParams: priority=64, loop=true, fadeIn=1s, 2D
  -> Assets/Res/Music/{AssetName}.mp3, group=Music
  -> 保存返回的 serialId
```

业务音效从 `DTSound` 读取组名、优先级、循环、组内音量和空间混合量，可绑定 `AEntity` 或指定世界坐标。UI 音效从 `DTUISound` 读取，固定走 `UISound` 组、非循环、2D。

## 核心类型与 API

| 类型/API | 职责 | 生命周期/线程约束 |
| --- | --- | --- |
| `PlayMusic(int)` | 单例式背景音乐切换 | 新音乐先让旧 serialId 淡出 1 秒 |
| `StopMusic()` | 停止当前音乐并清空静态 serialId | 仅跟踪经本扩展播放的最后一首音乐 |
| `PlaySound(int, AEntity, object)` | 播放并可绑定到实体 | Entity 销毁/隐藏后的具体停止行为由 UGF Sound 绑定逻辑负责 |
| `PlaySound(int, Vector3, object)` | 在世界位置播放 | 在 Unity 主线程调用 |
| `PlayUISound(int)` | 播放 UI 声音 | 固定 `UISound` 组、2D、非循环 |
| `IsMuted` / `Mute` | 查询/设置声音组静音 | 组不存在时警告；设置后立即 `Setting.Save()` |
| `GetVolume` / `SetVolume` | 查询/设置组音量 | 设置后立即持久化 |

## 数据与生命周期

- GameEntry prefab 当前配置三个组：`Music`（2 agents）、`UISound`（4 agents）、`Sound.Default`（4 agents），初始组音量均为 1。
- 音乐资源固定为 `Assets/Res/Music/{name}.mp3`；业务音效为 `Assets/Res/Sound/{name}.wav`；UI 音效为 `Assets/Res/UI/UISound/{name}.wav`。
- `s_MusicSerialId` 是静态可空整数，不检查声音是否已被其他代码提前停止；后续 `StopMusic` 仍会尝试停止该 ID。
- `ProcedureLaunch.InitSoundSettings` 在启动时恢复三组设置，默认音乐音量 0.3，其余音量 1，默认不静音。
- 场景加载成功后，GameHot 从 `DRScene.BackgroundMusicId` 切换背景音乐。

## 开发扩展步骤

1. 将 `.mp3` 音乐或 `.wav` 音效放入 `AssetUtility` 约定目录。
2. 按当前模式编辑音频表：GameHot 使用 `Design/Excel/GameHot/Datas/Game/Sound.xlsx`，ET 使用 `Design/Excel/ET/Datas/Game/Sound.xlsx`；填写唯一 ID、AssetName 和播放参数。
3. 若新增 SoundGroup，先在 `GameEntry.prefab` 的 UGF SoundComponent 配置同名组及 Agent 数量；表中的名称必须完全一致。
4. 运行 Luban 导出。GameHot 使用 `MusicId`、`SoundId`、`UISoundId`；ET 使用 `ET.Client.UGFMusicId`、`UGFSoundId`、`UGFUISoundId` 调用同一组扩展 API。
5. 需要额外播放参数时，先确认表结构和 `SoundExtension` 都消费该字段；只加 Excel 字段不会自动影响播放。

```csharp
GameEntry.Sound.PlayMusic(1);
GameEntry.Sound.PlaySound(SoundId.WeaponPlayer, playerEntity);
GameEntry.Sound.PlayUISound(10001);
```

## 约束与常见错误

- `DRMusic.Volume` 当前没有写入 `PlaySoundParams.VolumeInSoundGroup`，音乐始终使用 1；修改表中 Volume 不会改变播放音量。
- `DRSound.MaxDistance` 当前没有写入播放参数；表中该字段暂不生效。
- 当前生成的 `MusicId` 和 `UISoundId` 只有 `Undefined`，因为现有 Music/UISound 数据没有生成具名常量所需的 `CSName`；不要引用并不存在的 `MusicId.MusicMenu` 或 `UISoundId.Click`。
- ET 与 GameHot 的工作簿和 ID 类型不同。当前 ET Luban 配置 active、GameHot inactive；修改错误工作簿不会刷新当前导出结果。
- `Mute/SetVolume("Sound.Default", ...)` 保存键为 `Setting.Sound.DefaultMuted/Volume`，但 `ProcedureLaunch` 读取的是 `Setting.SoundMuted/Volume`。因此普通音效设置当前不能在重启后按同一键恢复；Music 与 UISound 没有这个名称差异。
- 表中的 `SoundGroupName` 若未在 prefab 注册，UGF 播放会失败；不要临时拼接组名。
- `PlayMusic` 只保证通过该扩展启动的音乐单实例；直接调用底层 `SoundComponent.PlaySound` 会绕过静态 ID 管理。
- `PlayMusic` 会先 `StopMusic()` 再查询 `DTMusic`；传入不存在的音乐 ID 会停止当前背景音乐并返回 null，不会保留旧音乐。
- 当前资源扩展名是硬编码的 `.mp3` / `.wav`，导入其他格式时必须同步改路径规则或转换资源。

## 验证方法

1. 导表后比对三个 `dt*.json`、生成 DR 类型和生成 ID。
2. 在 Unity 进入 Menu/Main，确认成功事件播放各自 `BackgroundMusicId`，切换时有 1 秒淡入淡出；额外用无效音乐 ID 验证旧音乐会被停止。
3. 从 SettingForm 调节三组静音和音量，确认即时生效并检查 Setting 键。
4. 重启后重点验证 `Sound.Default`；在修复键名差异前应能复现无法按 UI 保存键恢复的问题。
5. 分别从实体绑定和世界坐标播放音效，确认 2D/3D 混合量来自表配置。
