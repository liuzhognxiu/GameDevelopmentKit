# 模块 14：通用工具与定义

> Catalog ID: `UNITY-14`  
> 状态：`verified`  
> 最后核验：`2026-08-04`  
> 适用模式：GameHot / ET Client / Unity Runtime

## 模块定位

该模块收口 Unity 资源路径、GF 文本/JSON Helper、本地化字符串扩展、URI 转义、日志格式化和项目常量。它提供的是薄适配与约定，不包含 HTTP GET/POST 客户端、文件 IO 或业务服务。

## 依赖关系

- AssetUtility 依赖 GF `Utility.Text` 和部分 GameEntry 状态。
- Newtonsoft Helper 依赖仓库/UPM 中的 Newtonsoft.Json；ZString Helper 依赖 Cysharp.Text。
- BaseComponent 通过 prefab 中的类型名反射安装 Helper，业务使用 `Utility.Json` / `Utility.Text`，而不是直接实例化实现。
- StringUtility 依赖已经初始化并加载字典的 `GameEntry.Localization`。
- Constant 被场景、音频、UI、配置、资源和 Setting 模块广泛使用。

## 入口与调用链

JSON：`Utility.Json.ToObject<T>(json)` -> BaseComponent 已配置的 `Game.NewtonsoftJsonHelper` -> `JsonConvert.DeserializeObject<T>`。

文本：`Utility.Text.Format(format,args)` -> `Game.ZStringTextHelper` -> pooled ZString builder -> 返回普通 string。

资源：业务传逻辑名 -> `AssetUtility.Get*Asset` 拼接 `Assets/Res/...` 完整路径 -> UGF Resource/Scene/Sound/UI API。

本地化：`key.ToLocalization(args)` 直接转发到 `GameEntry.Localization.GetString`。

## 核心类型与 API

| 类型/API | 职责 | 生命周期/线程约束 |
| --- | --- | --- |
| `AssetUtility.Get*Asset` | 统一生成 Unity 资源路径 | 静态纯拼接；Localization(string) 读取当前语言 |
| `StringUtility.ToLocalization` | 本地化 Key 的 0-16 参数语法糖 | 字典加载前调用可能得不到业务文案 |
| `NewtonsoftJsonHelper` | ToJson/ToObject | `internal`；经 `Utility.Json` 使用 |
| `ZStringTextHelper` | GF 格式化实现 | 释放 builder，但最终 string 仍会分配 |
| `WebUtility.EscapeString` | `Uri.EscapeDataString` | 只编码单个 URI 数据，不发网络请求 |
| `WebUtility.UnescapeString` | `Uri.UnescapeDataString` | 非完整 URL 解析器 |
| `HyperlinkLogHelper` | 格式化堆栈路径 | 当前 GameEntry 未配置它 |
| `Constant.AssetPriority` | Config/DataTable/Dictionary 等加载优先级 | 编译期常量 |
| `Constant.Layer` | Default/UI 名称及运行时 ID | Layer 不存在时 `NameToLayer` 返回 -1 |
| `Constant.Setting` | 语言和声音持久化键 | Sound.Default 键名差异见 UNITY-09 |

## 数据与生命周期

- 当前 BaseComponent 配置 `Game.NewtonsoftJsonHelper`、`Game.ZStringTextHelper` 和 UGF `DefaultLogHelper`。
- 主要路径规则：Scene `.unity`、Music `.mp3`、Sound/UI Sound `.wav`、Entity/UIForm `.prefab`、Luban `.json/.bytes`。
- `AssetUtility.GetLocalizationAsset(string)` 使用当前 `GameEntry.Localization.Language` 和任意文件名；生成的 `GetLocalizationAsset(Language)` 使用显式语言和固定 `Localization.bytes/json`，两者不是同一签名。
- 生成器可能重写 Localization partial 的扩展名；手写 AssetUtility 不会随导出变化。
- `ZStringTextHelper` 每个 Format 都校验 null format，创建临时 ZString builder，最后 `ToString` 返回托管字符串。

## 开发扩展步骤

1. 新资源类型优先在手写 `AssetUtility` partial 中增加明确路径方法，并在调用模块集中使用。
2. 由工具控制的路径放在生成 partial，并修改生成器源而不是生成结果。
3. 新 GF Helper 实现对应 `Utility.*.I*Helper`，再在 GameEntry prefab 的 BaseComponent 配置完整类型名。
4. 新 Setting 键集中加入 `Constant.Setting`，写入和启动读取必须使用同一个键。
5. 新 Layer 同时配置 Unity Tags and Layers，并在运行时验证 ID 不为 -1。

```csharp
string path = AssetUtility.GetSceneAsset("Main");
VersionInfo info = Utility.Json.ToObject<VersionInfo>(json);
string title = LocalizationKey.Key_Menu_StartButton.ToLocalization();
```

## 约束与常见错误

- 旧草稿中的 `NewtonsoftJsonHelper.SerializeObject/DeserializeObject` 静态 API 不存在；请用 `Utility.Json.ToJson/ToObject`。
- `WebUtility` 只有 URI 转义与反转义，没有 GET/POST；网络请求应使用 `GameEntry.WebRequest` 或网络服务模块。
- `ZStringTextHelper` 是 GF Helper 实现，不是静态工具；“零 GC”并不准确，最终返回 string 必然分配，只是减少中间分配。
- 当前 `HyperlinkLogHelper` 未在 prefab 配置，Editor 的 GLogTool 也设置 DefaultLogHelper；不要依赖它自动处理日志。
- `GetShaderShaderVariantsAsset` 是源码中的实际方法名（含重复 Shader），调用时必须按现名，重命名需迁移调用者。
- 修改路径扩展名会影响资源收集、AssetBundle 和运行时加载，不能只改字符串方法。

## 验证方法

1. 对每个 AssetUtility 方法生成路径并确认目标资产真实存在及大小写一致。
2. 用 `Utility.Json` 对代表性 DTO 做序列化往返，覆盖缺字段、枚举和 null。
3. 用 `Utility.Text.Format` 覆盖 1、多个和 null format，确认 Helper 已安装。
4. 检查 GameEntry prefab 三个 Helper 类型名；替换后启动 Unity 验证反射创建无错误。
5. 校验所有 Constant.Setting 的写入点和读取点成对一致。
