# 模块 19：Unity 编辑器工具集

> Catalog ID: `UNITY-16`  
> 状态：`verified`  
> 最后核验：`2026-08-04`  
> 适用模式：Editor / GameHot / ET Client / ET Server

## 模块定位

本模块是 Unity 工程内的编辑期操作层：它把模式切换、资源与 Player 构建、热更程序集编译、ET 代码生成、外部 Tool/FileServer 启动、场景与目录快捷操作、资源清理、Inspector 扩展及 AgentBridge 命令接到 Unity Editor。业务工具主要分属 `Game.Editor`、`Game.ET.Editor` 和 `Game.Hot.Editor`，ET 库层还提供 `ET.Core.Editor` 与 `ET.ThirdParty.Editor` 两个仅限 Editor 的支撑程序集。

它不实现 Luban、Proto2CS、UGF ResourceBuilder、HybridCLR 或 AgentBridge 的底层能力，而是调用这些上游 API。运行时业务、完整构建发布说明分别由对应运行时模块和 `BUILD-01` 负责。

## 核心类型与 API

| 类型/API | 职责 | 生命周期/线程约束 |

| `CodeModeDefineSymbolTool` | 切换 ET Client/Server/ClientServer，可创建/删除 `Ignore.asmdef` | `UNITY_ET`；切换会触发 AssetDatabase Refresh |
| `BuildAssemblyHelper` | 调 Unity 编译 Player scripts、复制热更 DLL、Play 前临时禁用重复 runtime DLL | Editor；`CompileDlls` 同步阻塞，Play 状态回调移动 Library 文件 |
| ET/GameHot `BuildAssemblyTool` | 定义 DLL 清单、额外宏和目标资源目录 | 实现仅在 `UNITY_HOTFIX`；构建前特性也调用它 |

## 开发扩展步骤

1. 新增菜单工具：在 `Game.Editor`（通用）、`Game.ET.Editor`（ET）或 `Game.Hot.Editor`（GameHot）中放置 Editor 源码，为静态入口添加 `[MenuItem]`；写操作使用 Undo、SetDirty/SaveAssets，并为 Play 状态提供校验入口。
2. 新增主 Toolbar 控件：添加静态无参 OnGUI 方法并标注 `[Toolbar(OnGUISide.Left|Right, priority)]`；参考 `SceneToolBar`、`ReloadExcelToolBar`，显式处理 Play、异步重入和固定目标路径。
3. 新增 ET Code Creator：在 `Game.ET.Editor` 程序集中实现内部接口 `ICodeCreator` 的非抽象类；`CodeCreatorEditor.OnEnable` 会自动反射发现。模板放入 `Assets/Res/Editor/ET/Config`，生成前逐个检查所有目标，避免当前内置生成器的部分写入问题。
4. 新增自动编辑钩子：按场景选择 `AssetPostprocessor`、`CustomEditor`、`InitializeOnLoad(Method)`、`DidReloadScripts`、UGF 构建特性或 Unity 项目文件回调；不要假设所有工具都有菜单。
5. 新增 AgentBridge 命令：实现 `ICommandHandler`，提供稳定的 `Command`、`Description`、严格 `ParamsSchema` 和 `CommandBatchMode`；Prefab/Scene 分别实现保存与 Undo/dirty 语义。实际调用前必须通过运行时 `list_commands` 获取命令和 schema。

## 约束与常见错误

- `Game.ET.Editor` 与 `Game.Hot.Editor` 是否编译由 asmdef define constraint 决定；其 DLL 编译入口还要求 `UNITY_HOTFIX`。看不到菜单或 Toolbar 时先检查宏，而不是只检查源码。
- `DefineSymbolTool.Set_Luban_GenConfig` 只替换无空格的精确文本 `"active":false`/`"active":true`；手工改变 JSON 排版会使联动静默失效。
- `LinkXMLHelper` 依赖 `Assets/link.xml` 中约定的 `<!--SYMBOL-` 与 `-SYMBOL-->` 标记。标记缺失时不会创建新的 assembly 节点。
- Code Creator 的 UI 只校验名称非空且不含空格，不验证 PascalCase、路径分隔符或合法 C# 标识符。内置生成器按文件顺序写盘，遇到后续文件已存在才抛异常，因此“拒绝覆盖”不等于原子操作或可安全重复执行。
- `UIFormCodeCreator` 的 prefab 默认输出到 `Assets/Res/UI/UIForm/UIForm<Name>.prefab`，不是文档中常见的 `Hot/` 子目录；代码输出也位于业务 Model/Hotfix 目录，不在 `Generate`。
- DLL 复制前会清空整个目标代码资源目录及 `Temp/HybridCLRBin`。必须保证 DLL 清单完整，不能在这些目录放手工资产。
- `BuildHelper.BuildPkg` 最终只把 Launcher 传给 `BuildPipeline.BuildPlayer`；Launcher 启动后再加载业务场景。Toolbar 的 `BuildSceneSetting.AllScenes` 只影响 EditorBuildSettings。
- AssetClean、EntityTool、CodeMode 和模式切换会批量重写 prefab/scene、Excel、asmdef、配置资产或 XML。除平台切换、UPM 更新等个别入口外，多数没有二次确认，应先保证版本控制工作区可回滚。
- `EntityTool` 会删除并重建 Excel 的 `~未添加的实体` sheet；目标文件路径随 `UNITY_ET`/`UNITY_GAMEHOT` 改变。
- `FileTool.GetAllFiles(..., searchPattern)` 的当前实现没有使用 `searchPattern`，调用者不能依赖过滤参数。
- `GLogTool.SetAllLog` 当前重复写入 `Game.Log.Entity`，没有写 `Game.Log.Sound`；本次会话中的 Sound 开关会变化，但 Enable All/Disable All 后跨域重载的 Sound 持久值可能保持旧值。
- `ServerCommandLineEditor` 默认选择名为 `Localhost` 的 StartConfig；配置缺失时索引为 -1，窗口绘制时可能索引越界。
- `ReloadExcel` 的实现与日志文案不一致：它不导出 Excel，只刷新已生成资产并热重载配置。
- UPM 更新只处理 direct Registry 包和 manifest 中的 direct Git 包，跳过 Built-in、Local、Embedded；它需要网络，且更新期间可能触发脚本重载。
- Console 日志跳转通过反射读取 `UnityEditor.ConsoleWindow.ms_ConsoleWindow/m_ActiveText`，Unity 内部字段变化会使功能失效并回退到默认打开行为。
- `ComponentViewEditor` 会用反射直接 `FieldInfo.SetValue` 修改运行中的 ET Entity 字段，未提供 Undo 或业务校验；它只适合调试，不能当作持久化配置入口。
- `NavMeshExporter` 要求场景 NavMesh 已 Bake；输出目录与仓库内 Recast GUI 的 `Tools/RecastNavExportor/Meshes` 不一致，必须人工衔接并验证服务端消费路径。
- Shell 命令依赖 Unity 进程工作目录和已构建的 `../Bin`；Windows 使用 `cmd.exe`/`Tool.exe`，macOS/Linux 使用 `bash`/`dotnet Tool.dll`，平台差异必须保留。

- `Unity/Assets/Scripts/Game/Editor/Build/{BuildAssemblyHelper,BuildHelper,BuildSceneSetting,BuildToolEditor,LinkXMLHelper,UGFBuildEvent}.cs`：程序集/资源/Player 构建、场景、link.xml 和版本文件链。

- `Unity/Assets/Scripts/Game/ET/Editor/Game.ET.Editor.asmdef`、`Build/*.cs`、`DefineSymbol/CodeModeDefineSymbolTool.cs`：ET 程序集宏边界、DLL 清单、构建回调和 CodeMode 隔离。
- `Unity/Assets/Scripts/Game/ET/Editor/CodeCreator/*.cs`、`UI/UGuiFormCreateTool.cs`：反射发现、四类生成器、精确输出路径和 UIForm 域重载续作。

- `Unity/Assets/Scripts/Game/ET/Editor/{Helper,LogRedirection,PostProcessor,ServerCommandLine}/**/*.cs`：ET Logger、资源枚举、日志跳转、csproj/sln 改写和服务端窗口。
- `Unity/Assets/Scripts/Game/ET/Editor/Generate/Luban/*.cs`：8 个自动生成的 ET 编辑期 Luban 类型。
- `Unity/Assets/Scripts/Game/Hot/Loader/Editor/Game.Hot.Editor.asmdef`、`Build/*.cs`、`ToolBar/*.cs`：GameHot 程序集宏边界、DLL 编译/构建前回调及两个 Toolbar 入口。
- `Unity/Assets/Scripts/Library/ET/Core/Editor/{Tool,ComponentView}/**/*.cs`：`UNITY_ET_VIEW` 切换、Entity Inspector 和类型 Drawer。
- `Unity/Assets/Scripts/Library/ET/ThirdParty/Editor/RecastNavDataExporter/NavMeshExporter.cs`：Unity NavMesh 三角网格到 Recast OBJ 的导出入口与路径。
