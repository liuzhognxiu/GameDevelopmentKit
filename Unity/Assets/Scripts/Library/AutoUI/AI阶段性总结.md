## 作为Unity游戏程序员，AI都帮我做了什么

### 我们是怎么做出来一款游戏的（仅在游戏程序角度出发）

1. 技术选型
   我们对游戏框架的要求
    1. 易用性：易于上手，易于扩展
    2. 热更新：包括代码和资源的热更新
    3. 资源管理：简单易用的构建脚本，高效的资源加载和卸载机制，资源管线管理等等
    4. UI，事件，声音管理，场景管理，流程管理，状态机，行为树，表格以及自动化生成等等
    5. 网络通讯模块

2. 需求理解
   1. 需求评审
   2. 需求拆解
   3. 任务分配
   4. 表格设计

3. 资源准备
    1. 美术资源
    2. 音效资源
    3. 动画资源
    4. 特效资源
    5. 配置表
   
4. 资源导入
    1. 资源导入
    2. 预制体制作
    3. 场景搭建
    4. 表格导入

5. 功能开发
    1. 代码编写
    2. debug
    3. Review
    4. 测试
   
### AI能帮我们什么

我们的愿景永远是可以通过一句话，让AI直接帮我们生成一个符合我们设定的游戏，但是作为一个游戏开发者，深刻的理解这种“神笔马良”的工具，是要从一点一点的细节开始完成的
