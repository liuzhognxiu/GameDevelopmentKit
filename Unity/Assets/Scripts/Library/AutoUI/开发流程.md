# 开发流程总结

本文档总结了我们合作过程中建立和遵循的核心开发流程与规则。

## 一、核心开发流程：新增游戏内容（如子弹、武器等）

这是一个完整的功能开发闭环，严格遵循以下顺序：

1.  **资源准备 (Res)**
    *   由用户您在 Unity 编辑器中创建或修改 Prefab，并确保其位于 `g:\GameDevelopmentKitAI\Unity\Assets\Res` 目录下。

2.  **数据表配置 (Excel)**
    *   **实体表 (`Entity.xlsx`)**: 为新的游戏内容（如子弹、技能）添加一个唯一的实体ID。
    *   **枚举表 (`__enums__.xlsx`)**: 如果新内容引入了新的类型（如新的子弹类型），需要在此文件中添加对应的枚举定义。
    *   **功能表 (e.g., `Weapon.xlsx`)**: 在具体的功能表（如武器表）中添加新行，并使用来自 `__enums__.xlsx` 中定义的 **别名 (alias)** 来引用枚举值。

3.  **数据生成 (Gen All)**
    *   在完成所有表格修改后，我会提醒您在外部工具中执行 `gen all` 命令。
    *   我会等待您确认数据生成完毕。

4.  **项目编译 (Compile)**
    *   数据生成后，您需要在 Unity 或 Rider/VS 中编译项目。
    *   我会等待您确认项目编译成功，没有错误。

5.  **代码实现 (Scripting)**
    *   只有在上述所有步骤都成功完成后，我才会开始编写或修改与新功能相关的 C# 脚本逻辑。

## 二、数据表（Excel）管理规则

-   **文件路径**: 所有数据表源文件都位于 `g:\GameDevelopmentKitAI\Design\Excel`。
-   **新建表格**:
    1.  创建新的 Excel 文件后，必须删除默认的 `Sheet1`。
    2.  新的数据表必须在 `g:\GameDevelopmentKitAI\Design\Excel\GameHot\Datas\__tables__.xlsx` 中注册。
    3.  表格的第一列（A列）必须使用文本格式，特别是对于 `'##var'`, `'##type'`, `'##'` 等表头，需要以单引号开头写入以确保它们被识别为字符串。
-   **`__enums__.xlsx` 枚举表**:
    *   **定义**: 每个枚举项占一行。同一个枚举的第一个条目在B列填写 `full_name`，后续条目B列留空。
    *   **唯一性**: 如果枚举的各项是唯一的，应在第一个条目的D列将 `unique` 标志设置为 `TRUE`。
    *   **位掩码**: 如果枚举是位掩码（Flags），应在第一个条目的C列将 `flags` 标志设置为 `TRUE`。

## 三、C# 代码实现约定

-   **数据类 (`Data` Class)**
    *   如 `WeaponData.cs`, `BuffData.cs` 等实体数据类 **不会** 通过 `gen all` 自动生成，需要手动创建。
    *   它们继承自 `EntityData` 基类。
    *   其构造函数接收 `entityId` 和 `typeId`，并使用 `typeId` 从对应的 `DR` (DataTable Row) 类中获取配置数据进行初始化。
-   **UI界面 (`AUGuiForm`)**
    *   `AUGuiForm` 的子类应导入 `Game` 命名空间，但不应导入 `Game.UI`。
-   **数据传递**:
    *   向实体和UI传递初始化数据时，统一使用 `object userData` 参数。
-   **代码修改**:
    *   在生成新代码时，不应删除或覆盖原有的旧代码，以便于对比和审查。

## 四、沟通与协作规则

1.  **确认与澄清**: 在执行重要操作或不确定的修改前，我会先提出计划并寻求您的批准。
2.  **错误处理**: 如果操作失败，我会及时通知您并请求帮助以解决问题。
3.  **学习与迭代**: 我会从错误中学习，并根据您的反馈修正我的行为，将确认后的新流程和细节记录到我的永久记忆中。
