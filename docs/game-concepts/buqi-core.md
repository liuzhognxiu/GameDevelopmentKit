# 《不器》核心概念

> **状态**：正文为 2026-08-06 历史基线，描述终极形态与设计意图。当前可玩形态（Unity Demo）为单机离线无限天问道单局，战斗规则以 [确定性战斗契约 v0.6.0](buqi-battle-contract.md) 为准，内容规模为 300 件器物与 8 构筑方向。主线叙事已于 2026-08-23 按"十印问道·渡劫成道"方向重写（见 [剧情大纲 v0.3](buqi-story-outline.md)）。本文"详细文档"一节中 v0.4 系文档为历史基线，将在规格对账后统一修订。

## 一句话说明

《不器》是一款异步对战自动构筑肉鸽：玩家在战前购买、升级、改造和排列装备，组成一套自动运转的构筑，再与另一名玩家保存下来的对手快照交战。

## 通俗核心

玩家在战斗中不手动出牌，也不临场释放技能。玩家真正做的是在战前组装和调整一套自动战斗构筑。

每局游戏中，玩家会反复进行以下步骤：

1. 从少量弱装备开始。
2. 进入商店、事件或升级机会。
3. 购买新的装备。
4. 升级已有装备。
5. 接受带有代价的改造。
6. 调整装备的顺序和位置。
7. 与对手快照开始自动战斗。
8. 观察整套构筑如何运转。
9. 看懂胜负的主要原因。
10. 继续调整，直到本局胜利或被淘汰。

## 核心乐趣

乐趣来自战前构筑和战后调整：

- 现在购买，还是攒金币等待更合适的装备。
- 集中强化一个核心，还是让整套构筑更加稳定。
- 接受强力改造带来的过载，还是维持安全节奏。
- 通过位置、尺寸、冷却和触发顺序形成连锁。
- 构筑出一套能够击败其他玩家保存构筑的自动体系。

## 类型定义

《不器》是一款**异步对战自动构筑肉鸽**。

- **异步对战**：对手是其他玩家保存的构筑快照，双方不需要同时在线。
- **自动构筑战斗**：玩家负责战前准备，战斗开始后系统自动结算。
- **肉鸽单局**：每局拥有随机商店、事件、奖励、对手和构筑路线。

## 首阶段形态与终极形态

- **终极形态**：异步对战——对手是其他玩家保存的构筑快照，双方无需同时在线；联网只替换对手提供方，不改变单局与战斗核心。
- **首阶段（当前 Unity Demo）**：单机离线单局。对手为本地预制快照（PVE 题目池 + 本地玩家构筑池），不连接服务器、不上传构筑、不做实时匹配。
- 当前可玩单局为**无限天问道赛程**（对齐 The Bazaar 流程逻辑）：每日依次经历两次经营、PvE、两次经营、PvP，共六个时段；**境界是修为**（经验驱动，炼气至圆满九境）、**道印是胜场**（累计九胜后，下一次 PvP 进入天劫）、**道基是单局生命**（初始 20，PvP 失败扣当前天数，首次归零进入一次心魔试炼）；渡劫三阶段成功后获得第 10 胜。内容规模 300 件器物；当前 Demo 暂时保留战斗 v0.6 的 8 个构筑方向。

## 与传统牌组构筑的区别

传统牌组构筑通常要求玩家抽牌、管理手牌，并在战斗中逐回合出牌。

《不器》中，玩家购买和排列装备，战斗开始后不再操作。战略决策集中在两场战斗之间，而不是战斗中的每一个回合。

## 世界观说明

玩家是一名无门无派的散修，在移动城池“不器城”参加“百炼问道”。装备可以表现为法器、符箓、阵图或灵物，但所有玩法界面统一称为“装备”。玩家把装备排列在棋盘上，与问道台保存的对手构筑快照交战。

不器城本身也像一套由残缺技艺、建筑和居民组成的巨大自动构筑。它通过观察每一场百炼问道学习，并逐渐形成自己的意识。

主线命题是：

> 一条尚未完成的道路，有没有资格被称为大道？

## 统一术语

完整映射见 [玩法通用词汇表 v1.0](gameplay-terminology.md)。核心玩家词汇如下：

| 概念 | 统一词 |
|---|---|
| 自动触发的构筑单位 | 装备 |
| 当前装备与位置组成的方案 | 构筑 |
| 十格线性放置区域 | 棋盘 |
| 带收益与代价的装备修改 | 改造 |
| 单场战斗生命 | 生命值 |
| 单局失败次数资源 | 单局生命 |
| 防御资源 | 护盾 |
| 风险资源 | 过载；达到阈值触发过载伤害 |
| 保存的敌方构筑 | 对手快照 |
| 单局胜利进度 | 胜场 |
| 单局货币 | 金币 |

> **0.6.0 语义注**（以 `buqi-battle-contract.md` v0.6.0 为准）：充能 = 立即推进目标装备冷却的效果，不是装备持有的层数资源；急速/减速为固定 2 倍/0.5 倍且互斥；过载每达到 10 点触发一次 8 点真实伤害；沙暴自 30 秒起每 tick 递增真实伤害，无硬上限。

## 设计边界

首个可玩原型只验证一件事：

> 组装一套小型自动构筑，观看它与对手快照交战，再根据结果进行调整，这个过程是否有趣？

不器城、百炼问道和修仙故事负责赋予玩法意义，但不能用复杂设定掩盖这条通俗核心。
