## 1. 一页体验

《不器》是一款**异步对战自动构筑肉鸽**。玩家从四名英雄中选一位，在无限天的"百炼问道"赛程里购买、升级、改造、排列装备，拼出一套自动运转的构筑；战斗开始后不手动出牌，双方按连续冷却自动触发，战后用日志解释胜负。

- **首屏一句话**：摆好你的装备，让它们自己攻击、护盾、治疗和控场；战后看清败因，再改一次构筑。
- **核心验证问题**：玩家能否看懂输赢原因，并在下一轮据此主动改变购买、改造或摆位？
- **核心动词**：买（资源取舍）、摆（空间关系）、看（战后修正）。

## 2. 核心循环

```
选 1 名英雄 → 无限天问道赛程 → 十胜圆满 → 渡劫 → 成天道（胜利）
                                  ↘ 道基断绝（失败）
```

- **每天 6 时段**：晨(操作) → 午(操作) → 昏(PvE) → 午后(操作) → 操作 → 夜(PvP)。
- **双进度**：境界=修为（9 境经验制）、胜场=10 次 PvP 胜（PvE 只给修为）。
- **生命线**：单局生命 20（PvP 败扣=当前天数，归零→心魔试炼）。
- **渡劫**：第 10 胜 = 万法道影，三关三问，三式选一。
