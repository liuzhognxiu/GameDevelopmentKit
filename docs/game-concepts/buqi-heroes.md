# 《不器》英雄系统设定 v0.1

> 定位：玩家角色体系设定。玩家不再扮演"无名散修"，而是从多位有名有姓的**英雄**中选择一位，进入百炼问道。
> 体系对标 The Bazaar 英雄设计：**英雄 = 内容池过滤器 + 独有规则入口**（同一套战斗内核，每英雄拥有专属卡池、本命法宝、道途特质）。
>
> 变更记录：v0.1（2026-08-23）依据用户决策建立：首阶段 4 名英雄（阿瓷/闻辛/裴照川/荀照），按大巴扎"角色 + 专属卡片"密度包装，现有器物池可扩展归属。

## 1. 设计目标

1. **身份即玩法**：选英雄 = 选一套构筑语法。四名英雄共享同一战斗内核（0.6.0 契约），但卡池、法宝与特质组合出显著不同的学习曲线与构筑轴。
2. **叙事一致性**：英雄全部来自主线既有角色，弧光不被浪费——被选择的英雄由玩家亲自走完弧光；未被选择的英雄以"同期问道者"身份出现在事件与对手中，弧光在背景推进。
3. **内容可扩展**：英雄卡池是数据过滤器而非新战斗系统。新增英雄 = 新增一组专属卡 + 一条道途特质，不触碰内核。

## 2. 英雄构成（五件套）

| 组成 | 说明 | 实现落点 |
|---|---|---|
| 身份 | 姓名、来历、定位标签、专属开场 | 英雄表（Luban `DTBuqiHero`） |
| 专属卡池 | 只在该英雄的商店/事件/PvE 掉落/突破三选一出现 | `DTBuqiItem.Hero` 字段（0=通用，1~4=英雄） |
| 本命法宝 | 开局自带 1 件专属器物，有来历、可成长 | 开局配置 + 专属卡 |
| 道途特质 | 独有资源/规则（类 Bazaar 的 Ammo/Potion/Value） | 战斗内规则 + 专属 UI 资源条 |
| 突破奖励 | 境界突破三选一中混入英雄专属项 | 突破奖励表按 Hero 过滤 |

**共用部分（全英雄一致，保持平衡与收束统一）**：
- 双进度：境界=修为（9 境经验制）、道印=10 PvP 胜、道基=20（败扣=当前天数，归零→心魔试炼）。
- 初始生命值：**400**（全英雄一致，单场战斗生命）。
- 棋盘：10 格棋盘（拓扑待定）；器物尺寸 S/M/L 三档保留。
- 结局：十印圆满 → 渡劫之战（万法道影）→ 天道三形态。
- 日程：无限天，每日 6 时段。

## 3. 卡池结构

### 3.1 密度目标（对标 Bazaar）

Bazaar 每英雄专属池 117~152 件、通用池约 138 件。不器目标密度：

| 池 | 目标规模 | 首阶段落地 |
|---|---|---|
| 每英雄专属池 | 100~120 件 | 40~60 件（含本命法宝） |
| 通用池（无主器物） | 120 件 | 80 件 |
| 合计 | ~600 件 | ~260 件 |

现有 300 张 `W8-001..W8-300` 全部重新归属，缺口按英雄主题扩展（用户已确认"当前项目的卡片可以拓展"）。

### 3.2 现有器物归属原则

按主构筑方向与主题归入英雄池；无明显方向性的通用件入通用池：

| 构筑方向 | 归属 |
|---|---|
| fast 快攻 / 暴击 / 多重 / 弹药 | 闻辛专属为主，少量入通用 |
| buffer 护盾反击 / freeze 冰冻 | 裴照川专属为主，少量入通用 |
| chain 充能连锁 / 加速 | 荀照专属为主，少量入通用 |
| heal 治疗 / 经济 / 修复 / 价值 | 阿瓷专属为主，少量入通用 |
| poison 中毒 / burn 灼烧 | 主体入通用池；每英雄专属池各渗入 2~3 张变体（如阿瓷"丹炉余烬"、闻辛"淬毒阵图"） |

### 3.3 数据与过滤

- `DTBuqiItem` 增 `Hero` 字段：0=通用，1=阿瓷，2=闻辛，3=裴照川，4=荀照。
- 商店刷新、事件奖励、PvE 掉落、突破三选一：全部按当前英雄过滤（通用池 + 本英雄专属池）。
- 道影/复制/转化类效果的目标池：默认受英雄池约束（同 Bazaar Transform 规则）。
- 英雄表 `DTBuqiHero`：Id/名称/定位标签/典型方向/道途特质描述/本命法宝 Id/专属开场文本。

## 4. 四名英雄详设

### 4.1 阿瓷 · 残器铺主 —— 拾荒修复师

- **定位标签**：残器铺主（对标 Bazaar：Pygmalien，经济/价值/护盾回血）
- **典型方向**：经济成长、治疗续航、价值、修复
- **道途特质「残片」**：
  - 出售或碎裂（Destroy）器物时生成残片，数量=器物基础价的一定比例（品质越高比例越高）。
  - 残片上限 30，属战斗外资源，整备阶段消耗。
  - 用途一**修复**：消耗残片恢复一件被毁器物（复用 Repair 语义）。
  - 用途二**补丁**：消耗残片永久强化一件器物的数值（一次性，不可叠加同类补丁）。
  - 部分专属卡额外消耗残片触发效果（残片→护盾/治疗/充能转换）。
- **本命法宝「漏火丹炉」**：开局持有。低冷却治疗 + 每次使用生成 1 残片。来历：开场漏火事件中捡漏——"别人眼里的废炉，我看得出它是活的。"
- **专属卡池主题**：残器、旧货、补丁、回收、临时支撑。示例：`碎甲补丁`（护盾）、`旧剑磨刃`（攻击+出售价成长）、`拆解台`（出售价提高）、`丹炉余烬`（灼烧）、`撑杆`（邻接充能）、`药渣`（治疗）、`账本`（经济成长）。
- **开局场景**：众妙集漏火事件——漏火的丹炉、旧剑与护心铃意外成链；她第一个看出这是能运转的周天。荀照递上问道令："东西很破，路子倒是活的。"

### 4.2 闻辛 · 逐正弟子 —— 无瑕阵师

- **定位标签**：逐正弟子（对标 Bazaar：Vanessa，武器速攻/暴击/弹药）
- **典型方向**：攻击快攻、暴击、多重、弹药
- **道途特质「会心」**：
  - 己方效果链**完整触发不被中断**（无冰冻/无被毁/无触发失败）时，会心率 +X%（上限 50%）。
  - 被打断（自身被冰冻/减速生效/器物被毁）时会心率清零。
  - 会心使伤害/治疗/护盾/灼烧/中毒效果翻倍（复用既有 crit 词条，"会心"是它的无瑕连击式驱动方式）。
  - 会心溢出（达到上限后继续积累）可转化为一次多重（复用 multicast）。
- **本命法宝「私改阵图」**：开局持有。半张宗门标准阵图，高会心基础。来历：因私改标准阵图被逐出宗门时带出的唯一物件。
- **专属卡池主题**：标准阵图、私改件、刻度尺、试错记录。示例：`标准快攻阵`（攻击）、`私改刻度`（会心叠层）、`多重符`（多重）、`弹药匣`（弹药）、`校准尺`（会心锁定不清零）、`弃徒笔记`（事件）、`淬毒阵图`（中毒变体）。
- **开局场景**：带着半张阵图进城。"我不承认那是错的——我只是还没证明它对。"

### 4.3 裴照川 · 天衡院阵律官 —— 律令守护

- **定位标签**：天衡院阵律官（护盾反击=Pygmalien 护盾 × 冰冻控制=Vanessa 冰冻的混合位；大巴扎无专职控制英雄）
- **典型方向**：护盾反击、冰冻控制
- **道途特质「阵律」**：
  - 律令器物在整备阶段可选形态：护盾律 / 冰冻律 / 反制律（战斗中不可切换）。
  - 律令触发时积累「执法」层；达到 10 层触发一次全屏执法：对敌方全体造成反击伤害并生成护盾。
  - 执法层数在战斗结束保留（跨场积累，整备阶段可见）。
- **本命法宝「天衡令」**：开局持有。天衡院通行令牌，开局自带护盾律。来历：奉命记录百炼问道——"记录者也可以下场，代价必须亲眼确认。"
- **专属卡池主题**：律令、封条、结界、记录簿。示例：`护盾律令`（护盾）、`冰冻律令`（冰冻）、`反制律令`（反击）、`封条`（冻结一件敌方器物）、`结界`（邻接护盾）、`执法记录`（执法层加速）、`天衡档案`（事件）。
- **开局场景**：渡劫前夜台词前移——"如果凡人真的能成为天道，天衡院需要知道代价是什么。所以我来了。"

### 4.4 荀照 · 问道台看守 —— 道影守望

- **定位标签**：问道台看守（对标 Bazaar：Dooley，核心/协同引擎/加速）
- **典型方向**：充能连锁、攻击快攻、加速
- **道途特质「道影」**：
  - 每场 PvE/PvP 战后，可从对手构筑中**收录一件器物**入道影库（上限 3 件，可替换）。
  - 战斗开始时选择一件道影出战：占 1 格，属性按品质缩放，不可升级，但可被强化/修复。
  - 主题呼应：不器城通过百炼问道模仿学习，荀照是"看了一千年"的那个人——他学会了复刻对手。
- **本命法宝「守台铜钟」**：开局持有。全屏小幅度加速光环（复用 haste 语义）。来历：问道台的钟，敲了千年。
- **专属卡池主题**：铜钟、回声、回响器、看守手册。示例：`回声器`（充能传递）、`铜钟共鸣`（加速）、`守台手册`（道影收录上限+1）、`回响攻击`（攻击）、`道影强化`（道影数值提升）、`换班铃`（事件）。
- **开局场景**：千年看客终于下场，职务暂交学徒。"看了这么久，该轮到我自己排一套周天了。"

### 4.5 未选英雄：同期问道者

未被选择的英雄以"同期问道者"身份继续存在于本局：

- 出现在事件、商店台词与道影中（名字与构筑习惯保留）。
- 各自弧光在背景推进：选阿瓷时，闻辛是主要竞争者（"急于证明残法也能无瑕"的对手会反复同台）；选闻辛时，竞争位由其他同期问道者（NPC）承担。
- 首阶段只做事件化点缀（1~2 处特殊事件），不做完整支线。

## 5. 选人流程与开场

1. 主界面展示四名英雄卡面：立绘位、定位标签、典型方向、道途特质摘要、本命法宝预览。
2. 选择后进入专属开场（1~2 屏文字，交代来历与入场理由）。
3. 通用教学事件保留（买卖/摆位/周天教学）；漏火丹炉事件对阿瓷即本命法宝入手，对其他英雄为早期特殊事件（可购入）。
4. 荀照（问道台看守）递上问道令 → 进入问道之路。

## 8. 首阶段验收标准

1. 四名英雄各有 ≥3 条可辨识构筑轴，且有专属卡支撑（对照 §4 各英雄"典型方向"）。
2. 内容池过滤正确：商店/事件/PvE 掉落/突破三选一不出现他英雄专属卡。
3. 道途特质在战斗中正确生效且可回放：残片生成/消耗、会心叠层与清零、执法层与触发、道影收录与出战，全部进入战斗日志。
4. 平衡参考：每英雄 1000 场无头模拟，平均结束天数相近，10 胜率差距 ≤10 个百分点（首阶段参考线，非门禁）。
5. 现有 300 张器物全部完成归属（Hero 字段非空），归属表随卡池 DB 交付。
