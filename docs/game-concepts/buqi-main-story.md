# 《不器》主线故事基线 v0.3

> 状态：2026-08-23 更新。英雄制：玩家从四名英雄（阿瓷/闻辛/裴照川/荀照）中选择一位问道者，各带专属卡池、本命法宝与道途特质；主线按 The Bazaar 流程逻辑组织：百炼问道 = 无限天问道赛程，境界是修为、道印是胜场、道基是生命线、渡劫成道是终局。
>
> 完整设定见 [《不器》剧情大纲 v0.4](buqi-story-outline.md) 与 [《不器》英雄系统设定 v0.1](buqi-heroes.md)。

## 1. 故事定位

《不器》采用凡人流修仙问道气质：四名灵根寻常、无血脉传承的修士，在移动仙城不器城的百炼问道中，从炼气一路问道到十印圆满，渡劫成道。趣味来自坊市生活、奇怪法门、英雄专属构筑和"每赢一场、再进一步"的赛程节奏。

主线围绕一个问题展开：

> 一条尚未完成的道路，有没有资格被称为大道？

玩家在回答这个问题，不器城也在回答。**天劫就是裁判：走到尽头，天劫问的不是"你有多强"，而是"你愿意舍弃什么"。**

## 2. 世界基础

修仙界不缺功法，缺的是普通人能够得到的完整传承。宗门掌握成体系的真传，坊市里流通的则大多是残卷、旧法器、失败丹方、古怪灵物和无人愿意承认的试验品。

四名英雄都是灵根寻常、无血脉、无前世传承的修士，只愿意把别人眼中的废法拼成一套能够运转的体系——区别只在身份、来历与看待道路的方式。

天下没有预先写好的最强功法。每个人的道路都由每一次购买、取舍、排列和试错组成。

## 3. 不器城

不器城是一座不断迁徙的修仙城池。它会停留在云海、荒漠、群山或秘境边缘，钟声响过三次后便再次启程。

不器城没有唯一的建造者。它最初只是一艘供散修往来险地的破旧渡舟。此后有人在船上搭起药铺，有人接入废弃阵盘，有人用残破飞剑修补船舷。数百年间，无数修士用自己能够找到的东西修补它，它才逐渐成为今天的移动城池。

城中的街道是灵脉，店铺是阵眼，钟声是周天运转的节点。整座城并非由一颗可以取出的仙魂控制；建筑、法器、道影和居民共同组成了它尚且懵懂的意识。

## 4. 众妙集与百炼问道

不器城中最大的坊市是"众妙集"。炼器师、游方道人、散修和宗门弃徒都在这里交易法器、符箓、阵图与灵物。

坊市中央立着**问道碑**——自下而上刻满境界：炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘、圆满；碑顶一片空白，唯有天劫焦痕。**千年了，无人渡劫。**

问道台上，修士把法门排列为一套自动运转的周天，与问道台保存的"道影"交战。道影是其他修士某一时刻的构筑记录，不保留本人的意识，因此能够自然承载异步对战。

百炼问道表面是在选拔优秀散修，实际上也是不器城观察、记录和学习不同周天的方式。

## 5. 选人与开场

玩家在开场从四名英雄中选择一位问道者，各有来历与入场理由（详见英雄设定）：

| 英雄 | 入场理由 | 本命法宝 |
|---|---|---|
| 阿瓷（残器铺主） | 捡漏——漏火丹炉事件中看出别人眼里的废炉是活的周天 | 漏火丹炉 |
| 闻辛（逐正弟子） | 被逐出宗门，来证明私改的阵图不是错的 | 私改阵图 |
| 裴照川（天衡院阵律官） | 奉命记录百炼问道，也亲自下场确认代价 | 天衡令 |
| 荀照（问道台看守） | 看了一千年，该轮到自己排一套周天 | 守台铜钟 |

开场共同节点：漏火丹炉事件（阿瓷=本命法宝入手，其他英雄=早期特殊事件）、询问道台看守（阿瓷开场由荀照递令；荀照被选时由学徒看台）递上最低级问道令：

> "东西很破，路子倒是活的。进去试试？"

问道令上写着：**"炼气"**。玩家由此开始问道之路。

## 6. 问道之路（主线）

这条问道之路不是"五章剧本"，而是**一场无限天的问道赛程**，直到十印圆满、渡劫成道：

1. **境界是修为**：PvE、事件与问道都带来修为；炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 圆满，九次突破，每次突破都有仪式感的反馈与新的解锁。
2. **道印是胜场**：每次 PvP 问道胜利得一枚道印；PvE 胜利只涨修为，不给道印。**十印圆满，天劫降临。**
3. **道基是生命线**：初始 20 点；战败扣除等于当前天数的道基；归零触发一次心魔试炼，再败则道途断绝。
4. **渡劫是终局**：十印之战即天劫之战。对手是"万法道影"——历届问道者把所有赢法堆成的、毫无取舍的最强阵容。三关三问，三式三选一。**渡劫成功，飞升合道，成为新的天道。**

途中，未选英雄以"同期问道者"身份留在本局：阿瓷的货架随境界升级，闻辛（或同期竞争者）反复同台较劲又逐渐承认残法之路，裴照川在渡劫前夜抵达——不是阻止，而是记录。

## 7. 主要立场

- **四名英雄（玩家所选）**：道路可以在试错和取舍中逐渐形成；天劫只问道路，不问出身。弧光按英雄个性化（阿瓷=敢认好货，闻辛=敢认败绩，裴照川=敢认风险，荀照=敢认自己）。
- **不器城**：从模仿所有道路，成长为能够选择自己道路的生命；玩家成道那一刻，它第一次无需模仿任何人。
- **天衡院**：未经验证的混合周天可能伤及众生；"凡人成天"更是需要记录代价的未知。
- **众妙集居民**：他们依靠不器城生活，但对城市是否应当拥有自我并无统一答案。

冲突不以击败邪恶宗门为目标，而是让每一方的担忧都能够在具体事件和战斗中成立。

## 8. 结局：成为天道

渡劫成功即成为新的天道，天道形态由玩家一路的选择决定（详见大纲 v0.4 第 7 节）：定衡天道（秩序）、众修天道（众生）、自择天道（自由）。三形态都汇合到同一句：

> "下一程，试哪条路？"

## 9. 叙事原则

1. 核心玩法优先。故事解释境界、道印、道基、道影与渡劫，但不增加战斗操作负担。
2. 不把修仙词汇直接替换成职场词汇，也不依赖现实梗制造辨识度。
3. 英雄不是天命之子，特殊性来自玩家实际构筑出的道路；天劫只问道路，不问出身。
4. 英雄身份与专属卡一致：阿瓷的卡像旧货、闻辛的卡像阵图、裴照川的卡像律令、荀照的卡像回声——卡池本身就是角色的第一层人设。
5. 不器城前期只通过道路变化、钟声、问道台和异常联动表达意愿，不作为会长篇说话的任务发布者。
6. 轻快不等于规则随意。角色可以风趣，法门效果、道基损失和天劫的代价必须真实。
7. 首阶段原型只需要建立四英雄选人、众妙集、百炼问道、道影、境界与道印，不制作复杂过场或大量角色立绘。
