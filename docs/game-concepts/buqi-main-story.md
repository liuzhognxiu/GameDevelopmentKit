# 《不器》主线故事基线 v0.1

> 状态：2026-08-04 暂定。本文锁定故事方向和首条主线，不扩大首阶段可玩原型的制作范围。
>
> 完整章节因果、角色弧、关键分支与三种结局见 [《不器》剧情大纲 v0.2](buqi-story-outline.md)。

## 1. 故事定位

《不器》采用轻快热闹的修仙游历气质。趣味来自坊市生活、奇怪法门和严肃规则下产生的意外组合，不依赖现代职场映射或密集网络用语。

主线围绕一个问题展开：

> 一条尚未完成的道路，有没有资格被称为大道？

玩家在回答这个问题，不器城也在回答。

## 2. 世界基础

修仙界不缺功法，缺的是普通人能够得到的完整传承。宗门掌握成体系的真传，坊市里流通的则大多是残卷、旧法器、失败丹方、古怪灵物和无人愿意承认的试验品。

玩家是一名无门无派的年轻散修。他没有特殊血脉，也没有前世仙尊留下的完整传承，只愿意把别人眼中的废法拼成一套能够运转的体系。

天下没有预先写好的最强功法。玩家的道路由每一次购买、取舍、排列和试错组成。

## 3. 不器城

不器城是一座不断迁徙的修仙城池。它会停留在云海、荒漠、群山或秘境边缘，钟声响过三次后便再次启程。

不器城没有唯一的建造者。它最初只是一艘供散修往来险地的破旧渡舟。此后有人在船上搭起药铺，有人接入废弃阵盘，有人用残破飞剑修补船舷。数百年间，无数修士用自己能够找到的东西修补它，它才逐渐成为今天的移动城池。

城中的街道是灵脉，店铺是阵眼，钟声是周天运转的节点。整座城并非由一颗可以取出的仙魂控制；建筑、法器、道影和居民共同组成了它尚且懵懂的意识。

## 4. 众妙集与百炼问道

不器城中最大的坊市暂称“众妙集”。炼器师、游方道人、散修和宗门弃徒都在这里交易法器、符箓、阵图与灵物。

坊市中央设有问道台。修士可以在战前把法门排列为一套自动运转的周天，再与问道台保存的“道影”交战。道影是其他修士某一时刻的构筑记录，不保留本人的意识，因此能够自然承载异步对战。

百炼问道表面是在选拔优秀散修，实际上也是不器城观察、记录和学习不同周天的方式。

## 5. 主角开场

主角初到众妙集时，只想卖掉身上的几件旧物。一只漏火的丹炉、一柄旧剑和一枚护心铃在摊位上意外形成连锁。场面虽然混乱，问道台的看守却看出了其中可以重复运转的周天，于是递给主角一块最低级的问道令：

> “东西很破，路子倒是活的。进去试试？”

玩家由此参加第一次百炼问道。

## 6. 五章主线

### 第一章：破烂也能成道

玩家认识众妙集的商人和竞争者，学习购买、淬炼、排列与自动战斗。章节末尾，城中一条街道悄然变成玩家上一场周天的布局，暗示不器城正在学习。

### 第二章：城也会学坏

不器城开始模仿获胜构筑，却不理解构筑成立的原因。它铺设过量剑轨、让全城炉火同时加速，甚至为了触发反制而主动承受外部冲击。轻快混乱背后显露出一个问题：它学会了运转，却还没有学会选择。

### 第三章：天衡院来客

负责监察大型阵法和移动仙城的天衡院抵达不器城。天衡院判断，不器城正在形成自己的“道胎”，也即将迎来前所未有的城劫。

他们提出稳定可靠的方案：选定一套正统传承作为城市核心，封闭其他互相冲突的周天。这样能够保住城池和居民，却会让不器城停止学习，并失去刚刚形成的自我。

天衡院不是邪恶宗门。他们代表稳定、纯粹和可控制的道路，并有充分理由担心一座巨型周天失控。

### 第四章：谁在问道

玩家进入不器城最古老的区域，挑战历代百炼问道留下的特殊道影，最终发现百炼问道并没有隐藏的主持者。不器城自己延续了这场试炼，因为它一直通过众生的构筑学习何为大道。

它收集了无数获胜方法，却犯下与新手构筑者相同的错误：以为把所有强大的东西放在一起，就能成为最强的周天。

### 第五章：不器渡劫

城劫降临时，不器城创造出最终道影。这个道影拥有历代问道中最强的法门和联动，却因为缺少取舍而互相干扰。

玩家必须用一套方向明确、有所舍弃的周天击败它。胜利并非证明玩家拥有最强法门，而是第一次让不器城理解：

> 包容万法，不等于占有万法。  
> 不被一物定义，也不等于拒绝作出选择。

不器城主动舍弃无法共存的周天，按照自己的意愿完成变化，并以一座城池的身份渡过天劫。

结尾时，城门通往一个从未去过的方向，问道台只浮现一句：

> “下一程，试哪条路？”

## 7. 主要立场

- **玩家**：道路可以在试错和取舍中逐渐形成。
- **不器城**：从模仿所有道路，成长为能够选择自己道路的生命。
- **天衡院**：未经验证的混合周天可能伤及众生，稳定优先于自由变化。
- **众妙集居民**：他们依靠不器城生活，但对城市是否应当拥有自我并无统一答案。

冲突不以击败邪恶宗门为目标，而是让每一方的担忧都能够在具体事件和战斗中成立。

## 8. 叙事原则

1. 核心玩法优先。故事解释购买、构筑、道影和单局推进，但不能增加战斗操作负担。
2. 不把修仙词汇直接替换成职场词汇，也不依赖现实梗制造辨识度。
3. 主角不是天命之子，特殊性来自玩家实际构筑出的道路。
4. 不器城前期只通过道路变化、钟声、问道台和异常联动表达意愿，不作为会长篇说话的任务发布者。
5. 轻快不等于规则随意。角色可以风趣，法门效果、城市风险和天衡院的担忧必须真实。
6. 首阶段原型只需要建立众妙集、百炼问道和道影，不制作完整五章剧情、复杂过场或大量角色立绘。
