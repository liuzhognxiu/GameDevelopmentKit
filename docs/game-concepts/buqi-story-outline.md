# 《不器》剧情大纲 v0.4

> 定位：完整游戏主线的结构稿。主线按"百炼问道 = 无限天问道赛程"组织：境界是修为、道印是胜场、道基是生命线、天劫是终局。玩家从**四名英雄**中选择一位问道者（详见 [英雄系统设定 v0.1](buqi-heroes.md)），首阶段实现取"选人 + 单局完整问道 + 渡劫成道"的叙事闭环。
>
> 变更记录：v0.4（2026-08-23）英雄制——玩家不再扮演无名散修，改选四名英雄之一（阿瓷/闻辛/裴照川/荀照），各带专属卡池、本命法宝与道途特质；未选英雄成为"同期问道者"在背景推进弧光。v0.3（2026-08-23）按 The Bazaar 流程逻辑重写——10 次问道胜利（道印）完成本局、无限天赛程、Prestige 改为道基、境界改为经验等级（修为）；天劫重新包装为十印圆满后的渡劫之战。v0.2 的"五章主线/三种结局"体系废弃，三结局改造为"天道三形态"。

## 1. 核心命题

> 一条尚未完成的道路，有没有资格被称为大道？

玩家与不器城互为镜像：玩家用残缺法门拼出自己的周天；不器城用街道、阵眼、店铺、道影与居民拼出自己的意识。两者起初都想靠"收集更多强法"证明自己，最终必须明白，道路不是拥有了什么，而是愿意选择什么、舍弃什么，并承担什么后果。

天劫是这道命题的裁判：**走到十印圆满的尽头，天劫问的从来不是"你有多强"，而是"你愿意舍弃什么"。**

## 2. 故事基调

- 凡人流的修仙问道：四名英雄皆灵根寻常、无血脉、无传承，境界全凭一局局问道打出来——区别只在身份、来历与看待道路的方式。
- 比赛的热血与修行的仪式感并存：每次问道胜利都是一次"突破"，境界碑上的名字逐格亮起。
- 危机真实但不阴沉：天劫与道基（生命线）时刻提醒"这条路走不通"的可能。
- 不器城前期不会长篇说话，只通过钟声、道路变化、阵纹和对玩家构筑的模仿表达意愿。

## 3. 主要角色

### 3.1 可玩英雄（玩家在开场四选一）

玩家在开场选择一位英雄。四名英雄均来自不器城既有角色，各自拥有专属卡池、本命法宝与道途特质（完整设定见 [buqi-heroes.md](buqi-heroes.md)）：

| 英雄 | 身份 | 定位标签 | 本命法宝 | 道途特质 | 表层目标 |
|---|---|---|---|---|---|
| 阿瓷 | 残器铺主 | 拾荒修复师 | 漏火丹炉 | 残片（出售/碎裂得残片，修复与补丁） | 捡漏捡出一条大道 |
| 闻辛 | 逐正弟子 | 无瑕阵师 | 私改阵图 | 会心（无瑕连击叠会心，被打断清零） | 证明残法也能无瑕 |
| 裴照川 | 天衡院阵律官 | 律令守护 | 天衡令 | 阵律（律令选形态，执法层触发反击） | 亲眼确认"凡人成天"的代价 |
| 荀照 | 问道台看守 | 道影守望 | 守台铜钟 | 道影（收录对手构筑复刻出战） | 看了一千年，下场试试 |

- **角色弧共用结构**：从"再赢一把"的参赛者，走向"愿意为道路舍弃什么"的证道者；十印圆满之时，必须回答天劫的提问。具体弧光按英雄个性化（阿瓷=敢认好货，闻辛=敢认败绩，裴照川=敢认风险，荀照=敢认自己）。
- **内在缺口**：习惯把自己的方法称作"凑合/侥幸/公务/旁观"，不敢承认那是一条真正的路——天劫要他们承认的正是这条路。

### 3.2 同期问道者（未选英雄）

未被选择的英雄以"同期问道者"身份留在本局：出现在事件、商店台词与对手快照中，各自弧光在背景推进（首阶段只做事件化点缀）。

- 选阿瓷时，闻辛是主要竞争者——"急于证明残法也能无瑕"的对手反复同台。
- 选闻辛时，竞争位由其他同期问道者（NPC）承担。
- 荀照被选时，问道台看守职务暂交学徒；教程/复盘旁白承接者待定（TODO，见 buqi-heroes.md §7）。

### 3.3 其他立场

- **不器城**：由建筑、法器、道影和居民共同形成的懵懂意识，不存在可以取出的单一"城魂"。它通过百炼问道学习：模仿玩家构筑、学习玩家取舍；**玩家成道那一刻，城第一次无需模仿任何人。**
- **天衡院**：未经验证的混合周天可能伤及众生；"凡人成天"是需要记录代价的未知。裴照川是其在城中的代表。
- **众妙集居民**：依靠不器城生活，对城市是否应当拥有自我并无统一答案。

## 4. 双进度：境界与道印

### 4.1 境界 = 修为等级（经验驱动）

| 境界 | 定位 | 叙事节点 |
|---|---|---|
| 炼气 | 入门 | 首次问道，问道碑亮起 |
| 筑基 | 站稳 | 闻辛同台较劲 |
| 结丹 | 小成 | 坊市商人/训练师开启 |
| 元婴 | 成名 | 对手开始针对性构筑 |
| 化神 | 瓶颈 | "必胜丹方"骗局伏笔 |
| 炼虚 | 超脱 | 历代道影开放 |
| 合体 | 负重 | 取舍压力最强 |
| 大乘 | 巅峰 | 大乘圆满 |
| 圆满 | 临界 | 九境圆满，引动天劫 |

- 修为来自 PvE 胜利、事件与问道（胜负皆有，PvP 胜另得道印）。
- 境界提升 = 突破：获得成长奖励（三选一）并解锁内容（器物池段、商人、训练师、历代道影）。
- **境界不按胜场计算**——它与道印是两条独立的进度线。

### 4.2 道印 = 问道胜利（PvP 胜场）

- 每次 PvP 问道胜利得 **1 枚道印**；PvE 胜利只给修为，不给道印。
- **十印圆满 = 获得渡劫资格**，天劫随之降临。
- 道印同时是问道碑上的排名凭证——十印之上，碑顶千年空白。

### 4.3 道基 = 生命线（Prestige 化）

- 初始 **20 点道基**；每次 PvP 战败扣除等于**当前天数的道基**。
- 道基归零触发一次**心魔试炼**（最后机会）；再败一次 PvP 则道途断绝，本局结束。
- 道基是"根基"，不是血条——境界越高，失去根基的痛越真实。

### 4.4 无限天赛程

- 无固定天数。每天：晨/午操作（坊市、训练、事件）→ 黄昏 PvE → 午后操作 → 夜 PvP。
- 直到十印圆满（渡劫）或道基归零（道途断绝）。

## 5. 单局叙事弧（无限天问道）

各段按英雄身份做视角微调（阿瓷=买卖与捡漏、闻辛=阵图与胜负、裴照川=记录与风险、荀照=观看与复刻），节奏节点共用：

- **开场（选人后）**：专属开场交代英雄来历与入场理由；漏火丹炉事件（阿瓷=本命法宝入手，其他英雄=早期特殊事件）；荀照递上问道令。教学道影各有前主人一句话（复盘=读遗言）；首胜得印，境界碑亮起。
- **炼气期（第 1-2 印前）**：荀照复盘教学（旁白承接者 TODO，见 buqi-heroes.md §7）；首胜得印，境界碑亮起。
- **筑基-结丹（第 3-4 印）**：闻辛（或同期问道者）同台；阿瓷货架升级；坊市出现训练师。
- **元婴-化神（第 5-7 印）**：对手构筑开始针对你的路子；"必胜丹方"骗局出现（有人兜售必胜配方，实为诱导放弃自己道路的陷阱——闻辛险些中计，主角以战破局）。
- **炼虚-大乘（第 8-9 印）**：历代道影（前人道影的"遗言"难度逐级上升）；裴照川现身记录。
- **圆满-渡劫（第 9 印后）**：九境圆满，问道碑顶雷云聚集。**十印之战 = 天劫之战。**

## 6. 渡劫：十印之战

- **第 10 胜 = 渡劫之战**：对手是"万法道影"——历届问道者把所有赢法堆成的、毫无取舍的最强阵容，修途执念之影。四名英雄共用同一场渡劫之战（TODO：道影携带英雄元素，扩展期）。
- 天劫三问（三关），三式三选一（玩家决定如何回答天劫）：
  1. **直面天雷**：不取巧、不避让，用自己最强的构筑硬撼——成则证道，败则道消。
  2. **碎器证道**：主动碎掉最高品质器物，证明道路不由最强之物定义。
  3. **问心消劫**：燃尽道印（以一路取舍应答天劫），证明你记得每一场胜利为什么而赢。
- 三关全过 = **渡劫成功**。

## 7. 结局：成为天道（三形态）

渡劫成功即**飞升合道，成为新的天道**。天道形态由玩家一路的选择决定：

- **定衡天道**：合道后定下规则，封存危险道路，护佑众生安稳（秩序之天）。
- **众修天道**：把天道拆回万道，还给每个问道者——没有唯一的天，只有共同的道（众生之天）。
- **自择天道**：与不器城合一——城即你，你即天，继续永不停歇的旅程（自由之天）。

不器城收束：城一路模仿你的道路，**你成道那一刻，城第一次无需模仿任何人**——它学会了选择。终句不变：

> "下一程，试哪条路？"

## 8. 叙事原则

1. 核心玩法优先。故事解释境界、道印、道基、道影与渡劫，但不增加战斗操作负担。
2. 不把修仙词汇直接替换成职场词汇，也不依赖现实梗制造辨识度。
3. 主角不是天命之子，特殊性来自玩家实际构筑出的道路——**天劫只问道路，不问出身**。
4. 不器城前期只通过道路变化、钟声、问道台和异常联动表达意愿，不作为会长篇说话的任务发布者。
5. 境界、道印、道基的仪式感必须可见：突破反馈、道印入囊、道基受损，都要有明确的叙事与界面表达。
6. 首阶段只需要建立众妙集、百炼问道、道影、境界与道印，不制作复杂过场或大量角色立绘。
