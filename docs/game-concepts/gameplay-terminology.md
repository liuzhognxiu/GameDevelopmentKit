# 《不器》玩法通用词汇表 v1.3

> 目的：**双层术语**。**游戏术语**用于玩法规则、UI、代码；**包装术语**用于剧情与氛围文本。两层并存、各有用途，不混用、不互相替代。
> 规则：规则/UI/代码/测试/验收只写游戏术语；剧情、角色台词、氛围文案用包装术语。

## 1. 双层术语表（游戏术语 ↔ 包装术语）

| 游戏术语（规则/UI/代码） | 包装术语（剧情/氛围） | 定义 |
|---|---|---|
| 装备 | 器物 | 占据棋盘格并在战斗中自动触发的构筑单位 |
| 构筑 | 周天 | 玩家当前装备、位置、品质和改造组成的整体方案 |
| 棋盘 | 周天盘 | 放置装备的战斗区域 |
| 仓库 | 仓位 | 暂不放入棋盘的装备存放区 |
| 改造 | 淬炼、批注 | 附加在单件装备上的一项带收益与代价的修改 |
| 对手快照 | 道影 | 按同一规则保存的敌方构筑数据（异步对战的对手） |
| 胜场 | 道印 | 每次 PvP 问道胜利获得 1 枚；十印（10 胜）圆满引天劫 |
| 单局生命 | 道基 | 初始 20；PvP 败扣=当前天数，归零触发心魔试炼 |
| 金币 | 灵石 | 单局内购买、刷新、升级和改造使用的货币 |
| 生命值 | 气血 | 单场战斗生命；降至 0 时战败 |
| 护盾 | 护体 | 优先吸收普通攻击的防御资源 |
| 充能 | 蓄能、蓄力层数 | 一次性推进目标装备冷却的效果 |
| 沙暴伤害 | 劫火 | 默认 30 秒起、此后每基础 tick 递增的双方真实伤害 |

## 2. 战斗关键词（仅游戏术语，无包装层）

| 游戏术语 | 停用别名 | 一句话规则 |
|---|---|---|
| 攻击 | — | 先被护盾阻挡，护盾耗尽后扣生命 |
| 护盾 | 护体、缓冲 | 阻挡伤害；中毒绕过；对灼烧减伤 50% |
| 治疗 | 愈合 | 恢复至上限；清除 10% 中毒与灼烧 |
| 再生 | 生命恢复 | 每秒恢复配置量；可被暴击 |
| 中毒 | 毒蚀 | 每秒造成当前层数伤害，绕过护盾 |
| 灼烧 | 灼伤 | 每秒 2 点、层数 −1；有护盾减伤 50% |
| 冰冻 | 冻结 | 冻结期间不充能、不能使用 |
| 加速 | 急速 | 充能速度 2 倍 |
| 减速 | 迟滞 | 充能速度 0.5 倍；与加速互斥 |
| 充能 | 蓄能、蓄力层数 | 立即推进冷却（一次性，≠加速） |
| 暴击 | 会心 | 有几率效果翻倍（伤害/治疗/护盾/再生/灼烧/中毒） |
| 多重 | 连发 | 一次使用重复执行多次 |
| 弹药 | — | 耗尽停止充能、战后补满；容量 0=无限 |
| 飞行 | — | 受减速/冰冻时长减半 |
| 价值 | — | 经济收益（装备价值成长/出售价/金币） |

> 注：闻辛道途特质的世界观名"会心"、阿瓷的"残片"、裴照川的"阵律"是英雄专属机制的**包装术语**，实现时落到对应规则词（会心→暴击的连击驱动方式；残片/阵律→新机制，入契约 v0.7.0）。

## 3. 改造名称

| ID | 游戏术语 | 停用别名 | 一句话规则 |
|---|---|---|---|
| A-01 | 高速 | 加急 | 冷却缩短，但效果量降低（快但弱） |
| A-02 | 强效 | 延期 | 冷却延长，效果量提高（慢但强） |
| A-03 | 复制 | 复写、回响 | 首次主动触发后追加一次半效复制，不触发相邻响应 |
| A-04 | 抗减速 | 可靠 | 免疫敌方减速，但不能获得友方加速 |

## 4. 构筑方向

统一使用（7 种）：快攻、护盾反击、充能连锁、治疗续航、中毒消耗、灼烧压制、冰冻控制。

这些是分析标签，不是职业或硬克制关系。内部枚举 `fast/buffer/chain/heal/poison/burn/freeze` 保持不变。

## 5. 命名边界

- 玩法规则、按钮、状态栏、日志、测试步骤、验收条件**只使用游戏术语**。
- 剧情人物、地点、组织、事件、角色台词、氛围文案使用**包装术语**（如"不器城""百炼问道""道印""道基""器物"）。
- 代码类型名、字段名、配置 ID 和历史枚举暂不改名，例如 `BuqiItemConfig`、`daoSeal`、`spiritStone`、`EchoDefinition`；文档首次出现时用游戏术语解释，并可在括号内标注包装术语。
- 装备的显示名称可以有风格，但其效果描述必须使用 §2 战斗关键词。
- 禁止同一页面同时用"护体/缓冲/护盾"指同一资源；这不是世界观层次，是几份词典在抢方向盘。
