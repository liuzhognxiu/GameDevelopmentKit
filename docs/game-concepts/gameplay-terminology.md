# 《不器》玩法通用词汇表 v1.0

> 目的：玩法、系统、UI 和测试文档只使用常见游戏词汇。世界观专名只出现在剧情与氛围文本中，不能替代规则名。

## 1. 玩家可见核心词汇

| 统一词 | 停用包装词 | 定义 |
|---|---|---|
| 装备 | 法门、事项卡、卡牌组件 | 占据棋盘格并在战斗中自动触发的构筑单位 |
| 构筑 | 周天、自动周天 | 玩家当前装备、位置、品质和改造组成的整体方案 |
| 棋盘 | 周天盘 | 放置装备的 8 格战斗区域 |
| 仓库 | 仓位 | 暂不放入棋盘的装备存放区 |
| 改造 | 淬炼、批注 | 附加在单件装备上的一项带收益与代价的修改 |
| 对手快照 | 道影、影子档案、离线影子 | 按同一规则保存的敌方构筑数据 |
| 胜场 | 道印、席位章 | 单局内累计的胜利进度 |
| 单局生命 | 道基、权限值 | 玩家在本局还能承受的失败次数 |
| 金币 | 灵石、采购资金、资金 | 单局内购买、刷新、升级和改造使用的货币 |
| 生命值 | 气血、执行值 | 单场战斗生命；降至 0 时战败 |
| 护盾 | 护体、缓冲 | 优先吸收普通攻击的防御资源 |
| 充能 | 蓄力 | 装备持有并由效果读取或消耗的整数资源 |
| 过载 | 失衡、噪音 | 高收益效果累积的风险值 |
| 过载伤害 | 走火、噪音事故 | 过载达到阈值时触发的直接伤害 |
| 加时伤害 | 劫火、加班伤害 | 战斗超过 45 秒后逐步提高的双方直接伤害 |

## 2. 改造名称

| ID | 统一名 | 停用名 | 一句话规则 |
|---|---|---|---|
| A-01 | 高速 | 加急 | 冷却缩短，但每次主动触发增加过载 |
| A-02 | 强效 | 延期 | 冷却延长，非开战效果量提高 |
| A-03 | 复制 | 复写、回响 | 首次主动触发后追加一次半效复制，不触发相邻响应 |
| A-04 | 抗减速 | 可靠 | 免疫敌方减速，但不能获得友方加速 |
| A-05 | 稳定 | 静音 | 每次触发减少过载，但伤害和护盾降低 |
| A-06 | 超载 | 超额 | 伤害和护盾提高，开战时获得过载 |

## 3. 构筑方向

统一使用：快攻、护盾反击、充能连锁、治疗续航、中毒消耗、灼烧压制、冰冻控制、过载爆发。

这些是分析标签，不是职业或硬克制关系。内部枚举 `fast/buffer/chain/heal/poison/burn/freeze/overload` 保持不变。

## 4. 命名边界

- 剧情人物、地点、组织和事件名称可以保留世界观表达，例如“不器城”“百炼问道”。
- 玩法规则、按钮、状态栏、日志、测试步骤和验收条件必须使用本表统一词。
- 代码类型名、字段名、配置 ID 和历史枚举暂不改名，例如 `BuqiItemConfig`、`daoSeal`、`spiritStone`、`EchoDefinition`；文档首次出现时使用通用中文解释。
- 装备的显示名称可以有风格，但其效果描述必须使用攻击、护盾、治疗、充能、过载等通用词。
- 禁止同一页面同时用“护体/缓冲/护盾”指同一资源；这不是世界观层次，是三份词典在抢方向盘。
