# 《凡人修仙传》修仙体系与流派调研

> 调研目的：为游戏框架/《星期八》Demo 提供修仙题材的世界观与数值体系参考。
> 资料来源：原著（忘语）、网络百科与读者分析综合整理。
> 调研日期：2026-08-23

---

## 一、总体架构：三界九境（三段式）

《凡人修仙传》的修炼体系以**境界划分**为核心，按所在界面分为三大阶段，覆盖「凡人 → 下界大修 → 仙界大能」的完整路径：

| 阶段 | 所在界面 | 核心境界 |
|------|----------|----------|
| 下境界 | 人界 / 灵界过渡 | 炼气 → 筑基 → 结丹 → 元婴 → 化神 |
| 中境界 | 灵界 | 炼虚 → 合体 → 大乘 |
| 上境界 | 仙界 | 真仙 → 金仙 → 太乙 → 大罗 → 道祖 |

设计要点（对游戏化的启示）：
- **每个大境界之间存在明确战力鸿沟**，不能靠堆数值抹平。
- **每个大境界内部再分小层**（初期 / 中期 / 后期 / 大圆满），提供短中期成长节奏。
- **突破需要特定条件**（功法 + 资源 + 契机），而非单纯经验条满级。
- **天劫机制**是境界进阶的核心风险点，可作为游戏的高潮事件。

---

## 二、人界 / 下境界详解（前期主舞台）

### 境界与寿元速览

| 境界 | 小层划分 | 寿元 | 元神状态 | 核心能力 |
|------|----------|------|----------|----------|
| 炼气期 | 共 13 层 | ~100 年 | 气态 | 感应灵气、基础法术、符箓、低阶法器；尚不能辟谷 |
| 筑基期 | 初/中/后（+假丹） | ~200 年 | 液态 | 法力液化、辟谷、御剑短飞、小型阵法 |
| 结丹期 | 初/中/后/大圆满 | ~500 年 | 固态金丹 | 本命法宝、御空飞行、丹火炼丹炼器 |
| 元婴期 | 初/中/后/大圆满 | ~1000 年 | 婴儿状 | 夺舍重生、婴火、神识覆盖百余里 |
| 化神期 | 前/中/后/大圆满 | ~2000 年 | 元神 | 沟通天地元气、肉身不灭、撕空瞬移 |

### 关键设定

- **炼气期**：绝大多数修士的终点。层级 1–13 层，修炼速度完全取决于**灵根品质**（天灵根最快，四灵根最慢但后期有五行合一优势）。
- **筑基丹垄断**：筑基丹被大门派/世家垄断，是阶层壁垒的核心道具。
- **结丹雷劫**：结丹需渡金丹雷劫，成功率极低（约 1%），失败爆体。
- **元婴小天劫**：每约 300 年一次，雷劫强度随境界提升。
- **化神飞升**：人界灵气稀薄，化神后受界面之力排斥，须闯空间节点飞升灵界（成功率约 60–70%），失败形神俱灭。

> 原作设定：韩立飞升前，人界已万年无化神修士——体现资源枯竭 + 灵气衰退的「凡人流」底层逻辑。

## 三、灵界 / 中境界（中期主舞台）

| 境界 | 小层划分 | 寿元 | 核心能力 |
|------|----------|------|----------|
| 炼虚期 | 初/中/后/大圆满 | 理论永生（受天劫制约） | 元婴化虚、调动天地元气、五行合一门槛 |
| 合体期 | 初/中/后/大圆满 | 数万年 | 法体合一、初步借用天地法则 |
| 大乘期 | 初/中/后/巅峰 | 十万年+ | 法则大成、肉身重铸、飞升劫 |

- **大天劫**：炼虚 / 合体 / 大乘每约 3000 年一次，是灵界修士的主要淘汰机制。
- **五行合一**：进阶炼虚的硬门槛（天灵根需补全属性，四灵根反而天然占优）。
- **飞升准备**：大乘期需净灵莲、洗灵池、异魔金等资源，飞升成功率极低。

---

## 四、仙界 / 上境界（后期终极舞台）

仙界以**仙窍数量**与**法则领悟**为核心，战力差距几何级数增长。

| 境界 | 仙窍/标志 | 寿元 | 核心能力 |
|------|-----------|------|----------|
| 真仙境 | 12/24/36 窍 | 数十万年 | 仙躯凝聚、天人五衰前三衰 |
| 金仙境 | 60/84/108 窍 | 百万年+ | 法则之丝、初级灵域 |
| 太乙境 | 192/276/360 窍 | 近乎不朽 | 玉体蜕变、不再渡劫 |
| 大罗境 | 840/1320/1779 窍 | 真正长生 | 斩三尸、言出法随 |
| 道祖境 | 法则本源 | 与天同寿 | 某一法则的唯一至尊 |

- **天人五衰**：躯衰 / 仙衰 / 窍衰 / 魂衰 / 煞衰，是真仙→金仙阶段的核心风险。
- **三大至尊法则**：时间（金）、空间（银）、轮回（暗红），修炼者可越阶挑战。
- **道祖唯一性**：每个法则只容许一位道祖，使用法则会被天道吞噬。

## 五、流派与势力（宗门体系）

原作按**地域**划分势力版图，并非单一「门派排行榜」。核心舞台为**天南**（人界前期）。

### 1. 天南四大势力（人界前期格局）

| 势力 | 核心地盘 | 主导宗门 | 最高战力 | 定位 |
|------|----------|----------|----------|------|
| 正道盟 | 风都国及周边 | 太真门 | 至阳上人（元后） | 传统玄门，法统正宗 |
| 魔道六宗 | 天罗国 | 合欢宗 | 合欢老魔（元后） | 弱肉强食，内部竞争激烈 |
| 九国盟 | 九国山地 / 越国旧地 | 化意门 | 魏无涯（元后） | 多国联合体，对抗慕兰法士 |
| 天道盟 | 十余国「中立带」 | 鸾鸣宗 | 龙晗+凤冰（夫妻合体≈元后） | 松散自保，宗门最多 |

**天南三大修士**（各阵营一名元后）：至阳上人（正）、合欢老魔（魔）、魏无涯（九国）。

### 2. 魔道六宗（核心反派阵营）

| 宗门 | 特色 | 备注 |
|------|------|------|
| 合欢宗 | 双修/魅术 | 六宗之首，合欢老魔压阵 |
| 御灵宗 | 虫修 | 大长老东门图 |
| 鬼灵门 | 鬼道 / 毒术 | 魔道最弱，王蝉为韩立死敌 |
| 魔焰门 | 火属性魔功 | — |
| 千幻宗 | 幻术第一 | 大罗千幻决 |
| 天煞宗 | 妖魂 / 化身秘术 | 天煞真君 |

### 3. 正道代表宗门

- **越国七派**（韩立起点）：黄枫谷（韩立入门）、掩月宗、灵兽山、清虚门、化刀坞、天阙堡、巨剑门。后魔道入侵，六派远迁北凉国。
- **天道盟三宗**（云梦山）：落云宗（炼丹，韩立客卿）、古剑门（剑修）、百巧院（炼器）。
- **天南三大修士**所在：太真门、合欢宗、化意门。

### 4. 乱星海（中期主战场，内外海）

- **星宫**（内海人族至尊）：天星双圣（凌啸风+温青，元后）、少主凌玉灵；附属妙音门（紫灵仙子）。
- **逆星盟**（反抗联盟）：六道极圣（元后）、万法门、极阴岛（极阴祖师，韩立宿敌）。
- **中立**：六连殿（散修联盟）、外海海妖族群（七级妖兽≈元婴）。

### 5. 大晋（人界后期最高舞台，人族第一大国）

- 正道十大宗门：太一门（第一正道，藏隐化神）、岳阳宫等。
- 魔道十大宗门：阴罗宗（韩立多次交锋）、魔木宗等。
- **真灵世家**：陇家（真灵第一世家，有合体级）、叶家（皇族）、谷家——底蕴远超普通宗门。
- **千竹教**：人界傀儡术第一宗门。

### 6. 外敌与他界

- **慕兰法士**：草原游牧修士，五行术法，全民皆修；慕兰三老（三位元后）为边界大战核心对手。
- **天渊卫**（灵界）：神秘组织，曾一月剿灭上百家宗门。

## 六、对游戏化设计的启示（提炼）

1. **三段式成长曲线**：下/中/上三境界天然对应游戏的「新手村 → 中期大陆 → 终局仙域」三个大版本阶段。
2. **资源壁垒即阶级壁垒**：筑基丹、结丹材料、飞升资源是「凡人流」特色——可设计为**稀缺掉落 + 门派垄断**的经济系统。
3. **天劫 = 阶段 Boss 战**：小天劫（300 年）、大天劫（3000 年）、飞升劫天然适配周期性世界事件。
4. **阵营对抗骨架**：天南「正/魔/九国/天道」四足鼎立 + 乱星海「星宫/逆星盟」对抗，可直接套用为**势力战 / 阵营选择**玩法。
5. **灵根资质系统**：天灵根/多灵根差异 + 五行合一门槛，可作为**角色先天属性 + 转职路线**的数值基础。
6. **法则体系（后期）**：时间/空间/轮回三大至尊法则，可作为**终局 Build 分支**与 PVP 平衡锚点。

## 七、待补充 / 存疑项

- 原作境界名称在不同版本/同人中有「结丹=金丹」「化神=炼神」等异称，正式立项时建议统一术语表。
- 灵界、仙界势力在原作中展开较晚，本文以人界天南为主，后续可单独立《灵界势力》《仙界势力》子文档。
- 「流派」在原作中更偏**地域阵营**而非武学门派，若游戏需要「功法流派」（剑修/丹修/符修/傀儡等），需另行从功法体系维度拆解。
