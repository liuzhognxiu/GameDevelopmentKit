# 《The Bazaar》(大巴扎)三大初始英雄 完整攻略与卡片体系详解

> 覆盖英雄:**Vanessa(瓦妮莎)、Pygmalien(皮格马利安)、Dooley(杜利)**
> 这三位是游戏最早的核心英雄。本文档整合各英雄的定位、关键词机制、分档构筑(BD)、卡片体系分类与实战节奏。
>
> ⚠️ 说明:游戏数值随补丁频繁调整,单个英雄卡片数量达数百张(如 Pygmalien 逾 400 张)。本文档以**机制体系 + 分类全覆盖 + 代表卡详解**为核心,追求长期有效的构筑理解,而非易过期的逐张数值流水账。精确实时数值请以游戏内数据库为准。

## 第一部分:通用基础机制(三英雄通用)

### 1.1 棋盘与物品(Items)

- **棋盘容量**:玩家棋盘共 **10 格宽度**,物品按占位分为小型(1格)、中型(2格)、大型(3格)。
- **占位取舍**:大型物品数值强但占空间,配装的核心矛盾就是「格子经济」——如何在有限 10 格里塞进最高价值的组合。
- **稀有度(Rarity)**:分为 **Bronze(青铜)< Silver(白银)< Gold(黄金)< Diamond(钻石)** 四档,升级会同时提升数值和часто解锁额外效果。
- **附魔(Enchantment)**:物品可被附魔(如 Fiery 灼烧、Icy 冰冻、Deadly 暴击、Shielded 护盾等),为同一件卡片提供额外维度的强化。

### 1.2 技能(Skills)

- **被动技能**,不占棋盘物品格,提供全局增益(如「每有一件武器,武器伤害 +X」)。
- 技能是构筑的「粘合剂」,决定一堆物品能否形成协同(synergy)。

### 1.3 战斗核心关键词

| 关键词 | 机制说明 | 主要归属 |
|---|---|---|
| **Damage(伤害)** | 直接扣减对方血量,武器冷却结束时触发 | Vanessa 为主 |
| **Burn(灼烧)** | 每回合按层数造成伤害,可无视护盾 | Vanessa / Dooley |
| **Poison(中毒)** | 每回合按层数扣血,持续消耗,克护盾 | Vanessa |
| **Shield(护盾)** | 临时护甲,先于血量承伤 | Pygmalien / Dooley |
| **Heal / Regen(治疗/再生)** | 恢复血量 / 每回合回血 | Pygmalien |
| **Haste(加速)** | 缩短物品冷却,提高触发频率 | 通用 |
| **Slow(减速)** | 拉长对方物品冷却 | 通用 |
| **Freeze(冰冻)** | 暂停对方物品运作 | Vanessa |
| **Crit(暴击)** | 概率造成额外(通常 2 倍)伤害 | Vanessa / Dooley |
| **Value(价值/金币)** | 卡片本身或效果带来的经济收益 | Pygmalien |
| **Ammo(弹药)** | 限次使用,用尽后需重装 | Vanessa / Dooley |

### 1.4 经济与成长

- 每天(回合)有金币收入,用于在商店购卡、升级、刷新。
- **利息 / 收益类卡片**能滚雪球扩大后期资源,是 Pygmalien 的招牌路线。
- **升级节奏**:前期铺基础、中期定构筑方向、后期堆钻石级核心件。

## 第二部分:Vanessa(瓦妮莎)—— 攻击与元素爆发

### 2.1 英雄定位

Vanessa 是**纯粹的进攻型英雄**,主题为「海盗 / 武器 / 元素」。她拥有全游戏最丰富的**武器(Weapon)**池,以及灼烧、中毒、冰冻等元素控制手段。核心思路是**在对方打死你之前,先用高频高伤的武器或持续掉血效果解决战斗**。上手直观,是新手理解游戏的最佳入门英雄。

### 2.2 主流构筑(BD)分档

| 构筑名称 | 档位 | 核心思路 | 关键机制 | 优势 | 风险 |
|---|---|---|---|---|---|
| **武器速攻(Weapons / Crit)** | T1 | 多把高伤武器 + 暴击 + 加速,靠正面 DPS 秒杀 | Damage / Crit / Haste | 前期极强,思路简单 | 遇高护盾/回血阵容易被拖后期 |
| **灼烧(Burn)** | T1 | 叠高灼烧层数,让对方每回合持续掉血 | Burn / Haste | 克护盾,后期滚雪球 | 起手偏慢,需要凑件 |
| **中毒(Poison)** | T1-T2 | 堆毒层慢性消耗,无视护盾 | Poison / Regen 抵抗 | 极端后期无解 | 前期非常脆,易暴毙 |
| **冰冻控制(Freeze)** | T2 | 冻住对方关键武器,创造输出窗口 | Freeze / Slow | 强控节奏 | 输出不足需搭配武器 |
| **弹药(Ammo/Reload)** | T2 | 高弹药武器 + 快速装填连续爆发 | Ammo / Haste | 爆发窗口极高 | 弹药管理要求高 |

> **推荐上手**:武器速攻 → 灼烧。这两套容错高、前期强,适合新手滚起 win streak。

### 2.3 卡片体系分类

| 类型 | 作用 | 代表卡片(示例) |
|---|---|---|
| **武器(Weapon)** | 主力输出,冷却结束造成伤害 | Cutlass、Blunderbuss、Katana、各类火炮 |
| **灼烧源** | 施加/放大 Burn 层数 | 各类火焰武器与火药类物品 |
| **中毒源** | 施加 Poison,慢性消耗 | 毒液瓶、毒刃类物品 |
| **控制类(冰冻/减速)** | 打断对方节奏 | 冰冻装置、减速陷阱 |
| **加速/装填** | 缩短己方冷却、补充弹药 | Powder Keg、加速类道具 |
| **暴击/增伤** | 提升单次伤害上限 | 暴击强化件、瞄具类 |
| **技能(Skills)** | 全局武器/元素增益 | 「武器伤害提升」「灼烧翻倍」类被动 |

## 第三部分:Pygmalien(皮格马利安)—— 财富与防御

### 3.1 英雄定位

Pygmalien 是**经济与防御型英雄**,主题为「贵族 / 财富 / 收藏」。他并不追求快速击杀,而是通过**滚金币、堆护盾、堆回血**把对局拖入后期,再用「越有钱越强」的价值型卡片碾压。他的物品池带有大量与**金币收益、利息、价值**挂钩的机制,是三英雄中运营深度最高、也最「后期怪物」的一位。

### 3.2 主流构筑(BD)分档

| 构筑名称 | 档位 | 核心思路 | 关键机制 | 优势 | 风险 |
|---|---|---|---|---|---|
| **护盾流(Shield / Tank)** | T1 | 高护盾 + 护盾转伤害,以守代攻 | Shield / Value | 极稳,难被速攻 | 缺乏爆发,靠拖 |
| **价值/金币流(Value/Gold)** | T1 | 堆高单卡价值,越富越强 | Value / Economy | 后期无解滚雪球 | 前期脆,靠运营过渡 |
| **回血续航(Regen/Heal)** | T2 | 高再生 + 治疗,耗死对手 | Heal / Regen | 克灼烧以外的持续伤害 | 惧怕中毒/灼烧 |
| **护盾反伤(Shield-to-Damage)** | T2 | 把护盾数值转化为攻击 | Shield / Convert | 攻守一体 | 组件依赖强 |
| **大型物品(Big Items)** | T2-T3 | 堆钻石级大件,单卡质量压制 | Value / Size | 数值天花板高 | 格子紧张、成型慢 |

> **推荐上手**:护盾流最稳,适合学习运营节奏;熟练后过渡到价值流体验滚雪球快感。

### 3.3 卡片体系分类

| 类型 | 作用 | 代表卡片(示例) |
|---|---|---|
| **护盾件** | 提供/放大 Shield | 各类盾牌、护甲装置 |
| **价值/收藏品** | 高经济价值,升级后数值爆炸 | 珠宝、艺术品、收藏类物品 |
| **经济/利息** | 每回合生金、滚利息 | 保险箱、投资类道具 |
| **回血/再生** | 恢复与续航 | 药剂、治疗装置 |
| **护盾转化** | 把护盾变为攻击或其他收益 | 反射盾、转化核心 |
| **大型核心件** | 占位大但质量极高 | 钻石级招牌大件 |
| **技能(Skills)** | 护盾/价值/回血全局增益 | 「护盾提升」「每有 X 金币加成」类被动 |

## 第四部分:Dooley(杜利)—— 科技与协同

### 4.1 英雄定位

Dooley 是一台**机器人**,主题为「科技 / 核心(Core)/ 改装」。他的最大特色是拥有独特的 **Core(核心)系统**——可更换的机体核心决定他的基础运作方式,再围绕核心搭配各类「科技件(Tech / Gadgets)」形成引擎式协同。Dooley 是三英雄中**组合最灵活、combo 深度最高**的一位,能同时沾染伤害、护盾、灼烧、暴击等多路线,但对配件的连携要求也最高。

### 4.2 主流构筑(BD)分档

| 构筑名称 | 档位 | 核心思路 | 关键机制 | 优势 | 风险 |
|---|---|---|---|---|---|
| **弹药/暴击(Ammo-Crit)** | T1 | 高弹药武器 + 暴击 + 快速装填爆发 | Ammo / Crit / Haste | 爆发极高 | 弹药与冷却管理复杂 |
| **科技引擎(Tech/Gadget)** | T1 | 多个科技件互相触发,连锁增益 | Core / Synergy | 上限极高,combo 华丽 | 成型依赖凑件 |
| **护盾科技(Shield-Tech)** | T2 | 科技件驱动护盾滚动 | Shield / Core | 攻守兼备 | 需要核心配套 |
| **灼烧科技(Burn-Tech)** | T2 | 用科技件放大灼烧输出 | Burn / Haste | 克护盾 | 组件门槛高 |
| **加速堆叠(Haste Stack)** | T2-T3 | 极限压缩冷却,让引擎高速运转 | Haste / Core | 后期节奏碾压 | 前期弱、易被速攻 |

> **推荐上手**:弹药/暴击相对直观;科技引擎虽强但需理解连携,建议熟悉游戏后再玩。

### 4.3 卡片体系分类

| 类型 | 作用 | 代表卡片(示例) |
|---|---|---|
| **核心(Core)** | 决定机体基础运作,构筑地基 | 各类可更换 Core |
| **科技件/装置(Tech/Gadget)** | 触发式协同,连锁增益 | 各类小型科技道具 |
| **武器(含弹药)** | 输出主力,多带弹药机制 | 高弹药枪械类 |
| **护盾件** | 提供护盾,常与科技联动 | 护盾发生器 |
| **加速/装填** | 压缩冷却、补弹 | 加速模块、装填器 |
| **灼烧/暴击强化** | 元素与暴击输出维度 | 火焰模块、瞄准芯片 |
| **技能(Skills)** | 科技/核心/加速全局增益 | 「每有 X 科技件加成」类被动 |

## 第六部分:通用配装曲线与实战节奏

### 6.1 前期(第 1–4 天)

- 确定核心方向,围绕 1–2 张关键卡收件。
- Vanessa 追求早点凑出能打的武器;Pygmalien 优先经济/护盾过渡;Dooley 先定 Core。
- 不要贪多路线,格子和金币都有限。

### 6.2 中期(第 5–8 天)

- 明确 BD 主线,开始升级关键卡至 Silver/Gold。
- 补齐协同件(加速、技能、增伤),形成完整引擎。
- 根据对手调整:遇速攻堆护盾/回血;遇拖后期堆爆发/中毒灼烧。

### 6.3 后期(第 9 天以后)

- 核心件升至 Gold/Diamond,追求单卡质量与数值天花板。
- 优化棋盘布局:相邻触发类卡片注意摆放顺序。
- Pygmalien 此时进入统治期;Vanessa/Dooley 需确保爆发能在被拖死前打穿护盾。

### 6.4 克制关系速查

| 你的对手偏向 | 应对思路 |
|---|---|
| 高护盾(Pygmalien) | 上灼烧/中毒无视护盾,或极限爆发一波打穿 |
| 高回血(Pygmalien) | 中毒/灼烧持续压制,超过其回血量 |
| 速攻(Vanessa 武器) | 堆护盾+回血扛过前期,拖入后期 |
| 科技引擎(Dooley) | 用冰冻/减速打断其连携节奏 |
